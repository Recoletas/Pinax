## 2. 现状盘点（2026-10-10 对换基后 main 实测）

- **首页侧栏**（`LibrarySidebar` + 内嵌 `WorkspaceProjectNavigation`）：结构自上而下 = Pinax 品牌 → 项目导航组（我的作品/正文/助手/设定/资料/更多工具，带折叠 chevron）→ 跑团与冒险/联机房间 → 记忆与历史/备份与恢复/帮助中心/偏好与模型 → 「本地工作区」页脚。**工具组现悬在项目组之下，不贴底**；项目组折叠态未见持久化保证。
- **创作台右侧**：`AuthoringDock`（P1 起常驻，四段 tab：会话/执行/工具/Agent；会话段=助手对话，执行段=运行日志（可见性 Phase 3），非 ai 工具走 `#panel` overlay 盖在段上）+ 右轨 `AuthoringWorkspaceToolRail` 九钮（助手 + 推演/批注/大纲/角色/设定/现场/记忆/双栏，协作模式另有「协作」）。
- **创作台顶部工具栏**：撤销/重做/排版/快捷词/取名/生图/专注/校对/查找/助手（截图 2 现状）——已有「助手」钮（dock 开关位）。
- **双栏**：`AuthoringDualPane.vue` + 右轨 `dual` 钮 + `f2-dual-pane` Gate + ui-audit 相关断言。
- **提示词透明化**：`PromptPreviewPanel` + `usePromptPreview`（单开抽屉）+ `promptSnapshot`（会话内存 LRU 20）。现有三触点：体验页 `NarrativeTurn`（🔍）、创作台草稿卡 `AuthoringBlockDraft`（🔍）、助手回答 `AuthoringKnowledgeAssistant`（🔍）——**已不止酒馆**，但触点分散在各组件手工挂接，非 Agent 前端的内建保证。
- **体验域 Agent**：`NarrativeTurn` 独立前端（跑团对话流）。既有裁定：**两域（创作讨论流 vs 体验跑团流）不得混淆**。

## 3. 目标形态（逐面）

### 3.1 首页侧栏（R1/R5，小）
项目导航组默认展开（如折叠态有持久化则重置为展开为缺省）；跑团/联机 + 记忆/备份/帮助/偏好合并为一个工具组 **pinned 到侧栏底部**（`margin-top: auto`），与「本地工作区」页脚相邻；侧栏整体可收起（R1 的首页部分）。

### 3.2 创作台（R1–R4，主体）
- **右侧栏钉死 Agent**：dock 四段收敛——Agent（会话）为唯一默认板块；「执行」（运行日志）降为 Agent 面板内的次级入口（角标/抽屉，见待裁 2）；「工具」段退役（工具入口全部上顶栏）。
- **右轨退役**：八工具入口迁入顶部工具栏（排版/校对/查找等现有钮之后，按 推演/批注/大纲/角色/设定/现场/记忆 分组；带 pending 计数角标语义随迁）。点顶栏工具钮 → 右侧栏切换到该工具面板（复用现成 `#panel` overlay 机制与 `useAuthoringInspectorState` 状态机，只换驱动源）；再点「助手」（或同钮再点）→ 回 Agent。**Agent 永远是右侧栏的默认态**。
- **双栏退役**（R4）：工具钮、`AuthoringDualPane`、dock 双栏槽、`f2-dual-pane` Gate 与相关 ui-audit 断言整体删除；协作模式内该入口一并退役（见待裁 3）。
- **可折叠**（R1）：右侧栏收起=现成徽标钮形态（P1 已有），顶栏「助手」钮承担开/关切换；左侧章节树栏增加收起开关，两侧独立、状态持久（localStorage 偏好键，照 `writing_dock_preferences_v1` 惯例）。

### 3.3 提示词透明化全局化（R6）
🔍 从「各组件手工挂接」升级为 **Agent 消息渲染层的内建能力**：统一的消息壳组件挂一处 🔍，凡走 Agent 前端的消息（创作回答/草稿/体验回合/未来新面）自动具备；`promptSnapshot` 记录点下沉复核，保证任何 Agent 面的快照可查。**壳统一、数据流分域**——创作/体验两域的消息与工具流不合并（沿用既有裁定），统一的只是前端壳与透明化能力。

### 3.4 Agent 全局唯一（R6，节奏见待裁 4）
远期：体验页对话并入全局 Agent 壳（同一交互外壳、域感知内容）；本轮**不动体验页**，先在创作域把壳立住，体验域并壳另出独立提案。
