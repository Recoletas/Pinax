## 1. 作者路径与页面关系

默认路径：**当前书 → 设定 → 资料 → 添加/预览 → 选择用途 → 提取候选 → 审阅采纳 → 回正文**。资料应是设定区可持续管理的部分，不能只在“新建世界书”时出现。

先按当前设定页的目录、稿面、按钮原语完成资料代表片，再接入口和持久操作。右栏提供清晰的“资料”入口与当前书来源概况；复杂多文件管理复用同一资料工作面，避免在 440px 面板硬塞整页或复制两套状态。

| 现有模块 | 本轮职责 | 必须保住的关系 |
| --- | --- | --- |
| `WorldbookCreationWorkspace.vue` | 可恢复的创建/导入草稿，复用资料管理主体 | 旧 URL/未完成创建仍可进入；迁移入口不丢工作区草稿 |
| `StructuredSettings.vue` 及来源组件 | 资料管理的主要归属面，按分区提取 | 当前书、绑定世界书和原始来源始终明确；现有字段保存/草稿审阅继续可用 |
| `AuthoringWorldbookPanel.vue`、人物面板 | 发现资料、查看相关设定、回到资料管理 | 当前落笔处/全部筛选保留，使用已有 entries；不新增平行人物库 |
| `WorldBookEditor.vue` | JSON 兼容、条目/触发/分组等高级操作 | 与新入口共享导入预览/提交服务；不能两份导入逻辑各改一套 |
| 首页书稿导入 | TXT/MD 拆章成为正文 | 与“导入参考资料”明确区分，不自动把参考书当本书正文 |
| 素材/速记/画布/漫画 | 内容收集、创作草稿、视觉产物及引用 | 复用原素材 ID/媒体引用；资料原件不重复保存成素材副本 |
| 地图/历史 | 消费已采纳地点或有证据的事件 | 仅上传文件不生成正式地点/历史；不能覆盖原地图与时间轴 |
| 助手/推演/记忆 | 读取授权来源或已确认内容 | 原文可作为本次参考，但提取提案不能混成正式事实；与 N-C 共用证据身份 |
| 备份/存储 | 归档、容量、恢复、引用保护 | 来源原件/chunks/refs/工作区状态纳入既有 ZIP，禁止旁路清理 |

## 2. 数据与导入决策

- 当前项目以 `bookId → book.worldbookId` 为真源；全局管理可显式选世界书。禁止项目模式回退到全局 active。
- 未绑定的书：添加资料时按现有方式建立随书资料库并绑定，成功后再提交归属；失败保留可恢复草稿。导入已有 JSON 时先预览新世界书及关联目标。
- 已绑定的书：默认向当前资料库补充原始资料。JSON 默认作为可审阅的导入批次，选择新增/更新/跳过；“新建另一世界书并更换关联”是单独明确动作，不静默替换已有绑定。
- 多书共用一世界书：显示共享关系及影响书数；新增/更新属于共享库，书级提取任务、记忆和正文仍独立。不能悄悄克隆库或把共享事实等同全书共用私有记忆。
- 内容 hash 去重原件，但保留来源名、来源位置及各次导入关系。相同文件名不视为同版本；更新来源产生新版本，不覆写历史证据引用。
- “移出本书/库的资料”“删除归档原件”“撤回已采纳条目”是不同操作。移除前列影响引用；仍被历史、其他书或素材引用的原件不物理清除。
- 默认复用已支持的 TXT/MD/PDF/DOCX、粘贴和 JSON；扫描 PDF 明示需 OCR。EPUB/OCR 属后续能力，本夜不以假入口扩大承诺。

## 4. 最低验收矩阵

| 场景 | 预期 |
| --- | --- |
| 未绑定书添加资料、绑定写入失败 | 成功后只建一库；失败可重试，原书不误指向全局库 |
| 已绑定书 JSON 导入且存在同名条目 | 明确新增/更新/跳过，默认不覆盖；更新目标依稳定 ID/用户选择 |
| 两书共用库与第三本独立库 | 共享影响清楚；第三本零变化；书级任务和记忆无串域 |
| TXT/MD/PDF/DOCX/粘贴及损坏/扫描文件 | 成功/失败分开，原文字符可核对；不虚称 OCR 或全格式成功 |
| 关闭刷新、跨标签更新、导入中切书 | 草稿恢复到原范围；旧结果拒绝写当前书；正在编辑内容不被后台覆盖 |
| 源尾部含关键事实、长文分块 | 显示选取范围和覆盖情况；不能将首中尾抽样称为全书提取完成 |
| 移除被事实/素材/其他库引用的原件 | 先影响预览，不误删；旧证据仍可查或准确标记缺失 |
| 只增加参考资料但未采纳候选 | 地图/正式世界书/事实数不变；明确勾选后模型可引用原始资料 |
| 采纳人物/地点并在助手、推演使用 | 同一身份和版本；原文引用能定位，未授权/过期资料排除 |
| 配额不足、取消、重新打开及 ZIP 失败 | 原文不丢、失败状态可读、重试幂等、没有伪成功 |
