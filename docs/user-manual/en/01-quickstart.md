# Quick start

1. Open **Settings → Appearance → Interface language** and choose **English**. The choice stays on this device. Existing installations keep Chinese until you choose otherwise.
2. Choose **New manuscript**, enter a title and optionally choose a **Manuscript language**. A first chapter is created for you. AI and a story bible are optional.
3. To bring an existing draft, choose **Import TXT / Markdown**. Select a file up to 5 MB. Check the preview, titles, encoding and chapter layout before choosing **Create manuscript**. This creates a separate manuscript; it does not overwrite an existing one.
4. Write in the manuscript editor. Changes autosave. Use Ctrl / Cmd + Z to undo and Ctrl / Cmd + Shift + Z to redo. If saving fails, keep the page open and use **Retry saving** or **Export current text**.
5. Choose **Export chapter** or **Export manuscript** for readable UTF-8 Markdown. Use **Settings → Backup & restore → Workspace backup (ZIP)** for a workspace copy.

TXT heading detection supports standalone `Chapter 1`, `CHAPTER IV: The Door`, `Prologue` and `Epilogue`. Markdown headings also work. Ordinary sentences mentioning a chapter are not headings. If the preview is wrong, use **Import as one chapter** or edit the titles.

Your original titles and text are never translated by switching the interface. [Next: writing and review](./05-writing.md).
