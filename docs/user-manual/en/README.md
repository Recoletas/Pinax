# Welcome to Pinax

Pinax is a writing workspace for manuscripts, characters and worldbuilding. AI is optional: you can write, import, export and back up without a model connection.

Start with [Quick start](./01-quickstart.md), then [Writing and review](./05-writing.md). [Settings and backups](./07-settings.md) explains language preferences, model setup and how to keep your work safe. See [Troubleshooting](./08-faq.md) if something fails.

Your work is stored in this browser. There is no automatic cloud sync. Export backups regularly and before changing devices or application addresses.

English covers the main writing path. Some advanced tools and experiments still have Chinese labels or documentation. Switching the interface never translates existing manuscripts or model output.
