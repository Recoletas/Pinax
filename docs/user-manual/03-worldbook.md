# 世界书与设定

世界书汇集来源资料、人物、世界观和创作规则。关联书稿后，它为核心工作台中的特色 AI 功能提供作品背景。

## 从资料到设定

设定工作区按“资料 → 各项设定 → 高级条目 → 地图”理解和使用。资料页是准备世界书的起点；当前界面若打开的是“设定”，可点击分区中的 **资料** 切入。

### 资料页：导入与整理来源

在 **资料** 中添加已有文件，查看解析内容，并整理与当前作品有关的来源。TXT、Markdown、DOCX 和 PDF 可作为来源资料；这里导入资料与首页导入整本书稿是两个用途。

已有世界书可以使用相应的世界书导入入口。不想导入文件时，也可以直接手动填写设定。

### 各项设定：形成可使用的作品背景

在 **设定** 中整理世界观、故事核心、角色设定和创作规则。来源资料是参考，整理成的设定表达作者对这本书的正式选择；导入文件不等于其中所有内容都已成为正式设定。

### 高级条目：精细管理

界面中的 **条目** 用于逐条编辑、分组和关键词管理。需要更精细地组织 AI 参考资料时再使用，不必在开始写作前配置所有参数。

### 地图：补充地理关系

**地图** 用于查看和编辑地理信息。它目前尚未完全融入资料、设定和创作流程，按需使用；已有入口不代表所有地点、历史和推演都已自动联动。

## 给当前书稿添加一个人物

1. 打开要写的书稿。
2. 在右侧工具栏选择 **角色**，点 **新建人物**。
3. 先填写姓名和当前写作真正需要的内容，例如身份、说话方式或与主角的关系。
4. 保存后回到正文；再次打开角色栏即可查看或继续编辑。

如果这本书还没有资料库，第一次新建人物或设定时，Pinax 会自动建立并关联一份随书资料库。已有资料库也可以手动关联。

## 添加地点或规则

从当前书稿打开 **设定**，选择对应分类后新建内容：

- **人物**：身份、外貌、性格、说话方式和关系。
- **地点**：位置、氛围、地理特征和可互动事物。
- **规则**：世界如何运作，以及不能随意违背的条件。
- **创作约束**：文风、叙事边界或明确不希望出现的内容。

先写一条能直接帮助当前章节的资料，再逐步补充。资料较多时，可以从目录切换分类和条目；不必滚动一整份长文才能定位。

## 写作时怎样使用资料

人物和设定可以在工作台右栏查看，不要求离开稿面。AI 任务需要资料时，会按本次范围选择相关章节和条目；作者仍应检查实际参考范围和生成结果。

条目中的关键词用于在相关文字出现时选取参考资料。关键词太宽可能带入无关内容，太窄可能漏掉；这属于高级整理，第一次使用可以先保留简单名称。

## 导入或快速建立资料库

需要一次整理较多内容时，再进入独立的世界书页面：

- 从预设开始。
- 导入兼容的世界书 JSON，或从小说文本提取资料；SillyTavern 格式可用于兼容导入导出。
- 使用 **AI 建立基调** 生成待检查的世界概述和创作规则。AI 可用性取决于当前部署和模型配置，生成结果仍需作者确认。

同名世界书导入时，按界面选择重命名、同名并存或覆盖。覆盖前先检查影响并导出备份。

## 回到核心工作台

把世界书关联到当前书稿后，可以在工作台查看资料，并让相关 AI 功能参考本书人物、地点、规则和历史，开展查询、人物回应与情节推演。通用改写、续写和问答仍可独立使用；需要哪些资料，由具体功能的参考范围决定。
