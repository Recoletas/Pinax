# 世界书与设定

世界书保存作品的人物、地点、背景、规则和写作约束。你可以手动填写，也可以先导入资料，再选中来源让 AI 整理草稿。已有书稿需要先关联世界书，工作台才能使用对应资料。

![把正文片段粘贴进资料区后，页面显示已暂存的来源](../screenshots/user-guide-20260924/09-source-import.png)

## 页面里几类资料各管什么

从书稿的 **设定** 进入独立工作区，顶部各分区的用途是：

- **资料**：导入来源文件或暂存片段，保留后续核对的依据。
- **结构化设定**：作者确认后采用的人物、地点、世界观、故事核心和创作规则。
- **条目**：当资料变多时，进一步分类、分组并设置关键词等检索信息。
- **地图**：查看世界中的空间与地点关系。它是设定的一部分，不是正文画布。

正文中的段落是故事文本；世界书里的条目是可重复引用的资料；记忆账本记录带来源的故事事实和修订。这三层互相有关联，但不是同一种数据。

## 把一段文字存成来源

有文件时，在 **资料** 选 TXT、Markdown、DOCX 或 PDF；也可以直接粘贴正文、章节摘要或设定片段。导入前先确认文件里有可读文字：扫描版 PDF 只有图片时会提示需要 OCR。文件在本机提取文字，资料归档保存抽取内容和定位信息，不会把原始文件当作云盘上传。

粘贴一段文字后点 **暂存片段**。列表中出现这份来源后，打开检查内容是否完整。来源保存完成，但其中的人物和规则还需要整理为设定。

已有世界书时，先从顶部 **资料** 分区进入，再点添加。新建世界书时从 **设定 → 新建世界书** 打开资料区；如果暂时不想导入文件，也可以直接填写一句构思。

## 从来源整理结构化设定

打开结构化设定，按内容填写以下分区：

1. 在**世界观**写故事发生的年代、地点和背景边界。
2. 在**故事核心**写主人公当前目标、主要阻力和主要矛盾。
3. 在**角色设定**为会反复出现的人物写身份、关系、已知信息和不能轻易改变的特点。
4. 在**创作规则**写必须保持的叙述约束、风格边界或事实要求。
5. 需要时再补地点资料或其他设定。保存后回到工作台右侧 **设定** 或 **角色** 查看。

这些内容可以自己输入。也可以在创建工作区时选中部分来源、填写提炼方向，再点 **生成基础基调**。生成时只发送所选资料；长文会抽取开头、中段和结尾的代表片段。结果先进入预览，检查人物、事件和规则是否有原文依据，修正之后再确认建立世界书。不要把模型补出来的细节当作来源原文。

开始写作只需少量资料。例如人物第一次出场时，先记姓名、身份和这一场已经确认的事。没决定的关系、动机或背景先标为待定，不要为了填表让剧情提前定型。

## 把世界书关联到当前作品

回到书稿后，打开右侧 **设定**，选择 **关联世界书**，确认选择的资料库。关联后可在 **角色** 和 **设定** 面板里查看资料；写作助手中支持资料引用的任务可以使用关联内容。

关联不等于每次请求都带上整本世界书。发送问答、审稿或推演前，确认任务类型、引用范围和选区；回答里有来源时点回原文检查。没有世界书时，工作台的基础写作和一般 AI 写作协助仍可用，只是没有结构化人物、地点和规则供它查询。

## 高级条目什么时候用

条目适合需要细分资料或控制检索范围的作品。先为人物、地点或规则选合适的类型和分组，再写清可被复用的信息；关键词用来帮助匹配相关内容，不是给 AI 的隐藏命令。

刚开始可先用默认设置。等你发现助手经常找不到某条资料，或常把不相关条目一起带入时，再调整关键词和分类。每次修改后用一个具体问题试查，确认结果引用对了，再继续整理。

## 地图与正文的关系

地图用于记录地点及其空间关系。先在结构化设定或相关条目中确定地点，再到地图查看或整理位置；地图上的位置不能代替地点文字资料，绘制连接也不会自动证明两地之间存在道路或事件关系。用地图指导创作前，核对地点、关系和当前任务实际读取的资料。

地图页仍在逐步接入工作台的世界模型。遇到没有联动的字段，以页面能实际读取或显示的内容为准，不要假设地图上的每项编辑都已同步成正文规则。

## 写作时资料会怎样更新

Pinax 不会把每次输入都自动写成新的世界事实。正文中有角色自述、谎言、猜测、梦境和删改；直接自动确认会把未确定的内容固化。当前常见的数据流如下：

| 在写作中发生的事 | 处理方式 |
| --- | --- |
| 作者在角色/设定面板手动更改 | 保存到本书关联的世界书，由作者决定内容 |
| 正文附近识别到人物或地点 | 现场面板提供候选；检查、选择并保存后，才更新当前场人物/地点 |
| 正文可提取为故事事实 | 形成带来源的记忆候选；确认后写入事实账本，拒绝或修订会留下相应决定记录 |
| AI 根据设定给出回答 | 查看回答和原文依据；回答本身不会自动成为世界书条目 |

自动识别不等于自动定稿。比如一句“我想起长安”并不一定说明人物此刻身在长安；确认后再写入场景或世界资料。

## 世界书、记忆账本、正文历史

- **世界书**是作者整理和维护的设定库，回答“作品采用什么设定”。
- **记忆账本**记录故事中发生的事实、对应原文证据、时间信息、作者决定和后续修订，回答“这件事何时发生、根据哪段文字、后来有没有变化”。
- **正文历史**保存章节旧版本，用来比较或恢复稿件。

![设置中的记忆与历史：可切换修改记录、AI 候选和事实账本，当前作品尚无归档记忆](../screenshots/user-guide-20260924/07-history.png)

打开 **设置 → 记忆与历史**，先在“归属”里选当前作品，再切换 **修改记录、AI 候选、事实账本**。记忆修改由系统记录；需要作者确认的是 AI 提炼出的候选，而不是每条普通变更。正文版本在工作台的 **批注 → 版本** 或章节菜单 **历史版本** 中查看。若当前作品为空，页面会显示尚无已归档的记忆变更；这不代表正文历史也为空。

旧数据如果没有原始修订记录，只能保留现有快照，无法从当前稿件补出完整历史。记忆的存储方式与备份范围见[设置详解](./07-settings.md)。

## AI 会把哪些资料带进任务

支持资料引用的助手、查设定、找伏笔和推演任务，会按任务类型及本次选择读取相关片段，不会默认把所有来源和章节都发给模型。提交前看任务和范围；提交后看引用，再决定是否采用结果。配置的外部模型会收到完成该任务所需的正文和所选资料。若作品不宜发送到模型，使用手动整理、批注和正文编辑即可。

工作区数据的备份范围、资料原件保存方式和 AI 渠道说明见[设置详解](./07-settings.md)。
