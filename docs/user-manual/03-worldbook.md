# 世界书与设定

「设定」是你搭建世界、管理规则的地方，入口在顶栏（设定）。这里有三块：**结构化设定**（主工作台）、**世界书**（快速导入）、**世界地图**。

## 结构化设定

**结构化设定**（`/settings/structured`）是字段化的设定库，是你定义世界观的主工作台。它分几类维护：

- **人物**：名字、外貌、性格、说话方式
- **地点**：地理、氛围、可交互的东西
- **规则**：这个世界的特殊规则（比如"灵力耗尽会昏迷"）
- **创作约束**：想让 AI 一定遵守的风格 / 边界

字段化的好处是 UI 上能直接画表格、改下拉菜单，AI 也能按字段精确定位信息——不用靠它自己猜。

### 从零搭建

1. 进 **设定 → 世界书**（快速导入入口）
2. 用 **AI 建立基调**：写一段至少 8 字的说明，比如：
   > 修真 + 蒸汽朋克混合。1890 年代东方大陆，修士用灵石驱动机甲。
3. AI 会生成世界概述、文风、视角、基调和禁写边界
4. 点 **创建并进入结构化设定**，继续逐项填人物、地点、规则
5. 回 **体验** 选这个新世界，开写

## 世界书

**世界书**（`/settings/worldbook`）是这套设定的"快速起盘"入口：

- 选一个**预设**直接开始
- **导入**小说 / JSON 文本（支持 SillyTavern 格式导入导出）
- **AI 建立基调**：给一段描述，让 AI 自动搭出世界概述和创作规则

世界书按**条目**管理，每条有名字、分类（地点 / 角色 / 势力 / 事件 / 物品 / 规则）、触发关键词、正文、注入方式（常驻 / 按关键词命中才注入）和分组。

**同名冲突**：导入同名世界书时有三种策略——重命名 / 同名并存 / 覆盖。

> 世界书是**多本共存**的：切换世界只切换激活的那一本，导入过的都还在。要删某本世界书，去 **设定 → 高级设置** 的条目管理里操作。

## 高级设置

**高级设置**（`/settings/worldbook/advanced`）适合精细化维护：逐条编辑条目、改触发关键词、调整注入方式、做批量分组。追求 AI 写得准时，条目里的关键词命中是核心手段——写得好不好直接决定 AI 写得到不到位。

## 世界地图

**世界地图**（`/settings/world-map`）是基于程序生成的地图，能看地形、气候、生物群系、势力范围和道路网络。地图数据很大时生成会慢一些，这是正常的。

## 结构化设定 vs 世界书

两者互补：

- **世界书**管"原则、规则、风格、世界观"——自由文本，靠关键词命中注入
- **结构化设定**管"具体的人、具体的地方、具体的时间线"——字段化，AI 按字段精确定位
