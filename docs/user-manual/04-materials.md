# 素材

素材保存摘录、灵感和参考图。它们仍属于原作品，独立的旧素材工作台已停用；写作中收集和采用片段，在正文的素材收件箱操作，插画在画师里生成，漫画在漫画工作台制作。目录中的素材文件仍可打开查看。

## 从正文收一段

1. 在正文选中文字，在选区浮条中点 **素材**，保存时带上来源章节和原文位置。
2. 打开正文工具栏的 **更多 → 素材收件箱**，检查内容和来源。
3. 勾选需要的片段，再选择 **插入正文**、**加入纲要** 或相应的设定采用操作。收进素材不等于已经写回正文。

收件箱可按作品和类型筛选，暂时不用的片段可以归档或拒绝。跑团中 **收为素材** 的内容仍进入既有素材存储；正式人物和规则在[设定](./03-worldbook.md)里维护。

## 插画与漫画

在正文选中片段或定位文本块，点击 **生图** 打开画师。图片生成、选择和插入都在这里进行，操作前核对来源作品。图片的保存和插入是不同步骤，已有素材不会因为移除旧页面而被删除。

漫画可从左栏 **新建 → 漫画页** 开始，也可以在作品导航中打开漫画。改编时从漫画工作台选择正文或已有素材，再生成分页方案、制作画面。具体操作见[漫画](./09-comics.md)。

旧素材页书签会转到对应作品的画师；带有素材定位的链接会打开原素材。没有作品信息时返回首页选择作品。这里不会自动复制、移动或清空旧素材。
