# 素材

素材库保存摘录、灵感和待加工的片段。可以从正文选区收集，也可以手动新建，之后编辑、插回来源章节或送去制作分镜。人物和规则的正式资料放在[世界书与设定](./03-worldbook.md)。

## 从正文收一段

![从正文选中一段后建立的素材卡，显示原文、来源章节和待处理状态](../screenshots/user-guide-20260924/10-materials.png)

1. 在创作工作台拖选一句或一段文字。
2. 在选区浮条中点 **素材**。Pinax 会建立一张素材卡，并带上来源章节和原文位置。
3. 在素材页检查卡片内容、类别与状态。示例图中的卡片是“待处理”；这表示已经收进素材库，不表示已经写回正文或成为世界事实。
4. 可在卡片详情中编辑标题和正文、预览 Markdown，或用 **插回来源章节** 把选中的素材插回原章。插入前先确认光标位置。

也可以从素材页点 **新素材** 手动记下一条灵感。跑团记录中的描写或发现，则在体验页使用 **收为素材**；保存后仍要由你筛选和整理。

## 整理和继续使用

素材卡按类别和状态整理。常见类别包括灵感、正文候选、剧情事件、人物事实、世界书草稿、分镜种子和参考图。类别只是方便筛选的标签，不能代替设定页里的结构化人物或事件记录。

状态用于区分处理进度：待处理的卡片可以继续编辑；决定采用后再标为已采纳；暂时不用可归档。批量操作前先确认勾选项，删除是移除素材，不等于归档。

右侧副阅读台提供 **相关素材、插画生成、漫画制作** 等入口。选中卡片后，可以将它送到编导画布，或带入漫画改编。生成图像和改编方案需要相应模型；整理、编辑已有文字不需要。

插画生成以当前打开的素材为来源。生成图保存到它所属作品，批量勾选其他卡片不会改变图片归属；同一张图再次保存不会重复建立图片素材。插入速记前确认图片与当前素材属于同一作品；未归书的全局素材可使用同范围的图片，不能自动把另一书的图片转过来。已被素材或正文使用的图片不能通过删除生图候选移除文件。

## 送到编导画布或漫画

![一条已选素材进入漫画分页工作区；这里展示的是生成前的输入，不是模型生成的页面方案](../screenshots/user-guide-20260924/13-comics.png)

点 **导当前到画布**，素材会以节点出现在[视频与编导助手](./06-storyboard.md)的场景板中。节点进入画布后，还要进一步加入时间轴或节拍，才能形成镜头顺序。

点 **漫画制作** 会把选中的素材带到漫画页。确认素材后再点 **生成分页方案**；这是需要模型的步骤。生成后比较候选方案、检查每页节拍和对白，再决定是否进入整页制作。

素材的任何建议或生成结果都不会自动替换正文。想了解漫画后续编辑与导出，见[漫画](./09-comics.md)。
