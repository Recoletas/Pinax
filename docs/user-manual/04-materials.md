# 素材

**素材**（`/materials`）是冒险和写作过程中沉淀下来的内容库——金句、关键事件、重要描写、灵感碎片，先收集到这里，再决定怎么用。

## 素材从哪来

- 冒险里 AI 自动识别到的"值得记住"的信息（进记忆面板，见 [体验模式](./02-experience.md) 的"记忆"一节）
- 体验页 / 写作页里手动 **收为素材** 的选中文字
- 自己新建的素材卡

## 素材类型

素材按内容分成几类，方便你之后筛选：

- 分镜种子（storyboard-seed）
- 参考图（reference-image）
- 草稿片段（draft-prose）
- 事件（event）
- 角色事实（character-fact）
- 世界书草稿（worldbook-draft）
- 灵感（inspiration）

每条素材还有状态：**待处理 / 已采纳 / 已归档 / 拒绝**。

## 操作

- **勾选**多条后能批量操作：导入（到画布）、合并、采纳、归档、删除
- **导当前到画布**：把主卡片直接送入 [卡片画布](./06-storyboard.md)，画布上会多出对应的节点
- 已送入画布的素材会带 **「已入画布 ✓」** 标记，之后点按钮变成 **「打开画布节点」**
- **素材顾问**：拿不准一条素材要不要采纳 / 送画布 / 扩写，可以让 AI 顾问给建议

## 副工作台：插画与漫画

素材页右侧的**副工作台**有三种模式：

- **相关素材**：展示与当前选中素材同类的其他素材，点选即切换
- **插画生成**：选中一条素材（或用当前主题），描述你想要的画面，AI 生成插画；结果可以**存回素材库**（参考图 / 插画），或直接插入正文
- **漫画制作**：跳转到 [漫画](./09-comics.md) 工作台，按素材做多页漫画

## 素材的流向

素材是"内容池"，流向几个方向：

1. **画布**——把素材变成节点，连成时间轴，做分镜、生图、生成视频
2. **写作**——在写小说时，素材可以作为"续写参考"，或直接收进正文
3. **插画 / 漫画**——用素材内容生成插画（副工作台「插画生成」），或把素材送进 [漫画](./09-comics.md) 做多页改编

> 想导入新的世界书？那是 [世界书与设定](./03-worldbook.md) 的事，不在素材页。
