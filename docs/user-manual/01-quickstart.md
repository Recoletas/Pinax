# 快速开始

这一页先完成新建、输入、批注和保存。AI 改写是可选步骤。

## 1. 新建或导入书稿

![首页的新建作品入口](../screenshots/user-guide-20260924/01-home.png)

**从空白开始**：点“新建作品”，填写书名，再点“创建并开始写”。进入工作台后会有第一章，可以直接输入正文。

想先讨论故事时，选择“和助手构思”，点“创建并构思”；书名可以稍后再定。助手里的构思起点只会填入问题草稿，点发送后才开始回答。

**已有稿件**：点“导入书稿”，选择 TXT 或 Markdown。在预览里检查文字是否正常、章名和拆章位置是否正确，再确认导入。导入会新建作品，不会追加到当前章。

PDF、DOCX 用作参考资料时，从设定工作区的“资料”导入，见[世界书与设定](./03-worldbook.md)。

## 2. 写字，确认保存

![工作台：左边章节，中央正文，右边为已打开的工具面板](../screenshots/user-guide-20260924/02-workbench.png)

点击中央正文区输入文字。左边点击章节可切换稿件；右边工具按需要打开，暂时不用可以关闭。

观察编辑区的保存状态：从“未保存”变为“已保存”后，本次改动才已写入当前浏览器。如果一直未保存或出现失败提示，先复制仍在页面里的文字，或用“导出当前正文”留底，再按[常见问题](./08-faq.md)处理。

## 3. 给一句话加批注

![正文选区对应的批注显示在右侧](../screenshots/user-guide-20260924/03-annotations.png)

1. 在正文中拖选一句话，松开鼠标，点选区浮条中的“批注”。
2. 在批注框里写意见，例如“这里先别透露来历，让回答带一点试探”，再点“添加”。
3. 右栏出现这条批注，原句仍保留。可以继续编辑或删除批注。

批注不需要 AI。若浮条没出现，先在可编辑正文中重新选一段；详细排查见[常见问题](./08-faq.md)。

## 4. 可选：按批注改写

有可用文本模型时，点这条批注的“按批注改写”。没有模型时，先到“设置 → AI 配置”选择配置并测试连接。

生成后对照原文，检查人物说了什么、事实有没有被改动、上下句是否接得上。确认后再采用；不满意可关闭候选，原文保留。生成期间如果改过原句，旧候选可能无法直接采用，需要重新生成。

## 5. 导出一份备份

到“设置 → 备份与恢复”，选择“导出完整工作区（ZIP）”，保存下载的文件。更换浏览器、设备或网址时，在新环境选择“恢复备份”，先看预览，再确认恢复。

“导出当前正文”适合把文字拿到别的软件中继续写；完整工作区 ZIP 用于迁移书稿和相关资料。两者的范围不同，详见[设置详解](./07-settings.md)。
