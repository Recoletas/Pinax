# 快速开始

Pinax 默认从写作开始。第一次打开首页，只需要在下面两种方式里选一种；世界书和 AI 都不是前置条件。

## 从空白开始

1. 在首页点 **开始写作**。
2. 填一个书名，点 **创建并开始写**。简介和世界书都可以以后再补。
3. Pinax 会自动建立“第一章”并把光标放进正文，直接开始写即可。正文会自动保存在当前浏览器。

从首页进入的新建或导入流程，稿面标题下会显示一条可关闭的首次创作指引。它一次只提示当前下一步：先落正文，再建一个关键人物、安排当前场，最后打开推演；完成一步后会按实际书稿状态继续，不会盖住正文，也不会直接修改作品。

写到需要帮助时，再从右栏打开批注、设定、推演或助手。AI 生成的内容不会直接替你改正文，先看过，再决定是否采用。

## 带入已有书稿

首页点 **导入已有书稿**，或在创作页的空状态 / “更多”菜单选择 **导入 TXT / Markdown**。

导入分三步：

1. 选择一个 `.txt`、`.md` 或 `.markdown` 文件，最大 5 MB。Pinax 会自动识别 UTF-8、GB18030、Big5 和 UTF-16；若置信度不高，可以在预览页手动换编码。
2. 预览识别结果，确认书名和章名；可以按标题自动拆章，也可以整篇作为一章。
3. 点 **创建书稿**。Pinax 会新建一本书，不覆盖已有书稿，然后直接打开第一章。

选择文件和预览都不会写入；只有最后确认时才会创建书稿。Markdown 的一级、二级标题和常见的“第一章 / 序章 / 后记”等中文标题可以用于拆章；识别不合适时，选择“整篇作为一章”即可。

第一次在右栏新建人物或设定时，Pinax 会自动为当前书稿建立并关联资料库。已有资料库仍可以从“关联已有资料库”手动选择。

## 先知道数据放在哪里

作品保存在当前浏览器，不会自动同步到其他浏览器或设备。无痕窗口、清除浏览数据或浏览器存储异常都可能让本地内容消失。

写作一段时间后，打开首页的 **备份**，或进入 **设置 → 存储 → 导出本地作品备份**，把 JSON 文件保存到可靠的位置。作品备份默认不包含你自己填写的模型 API Key，也不包含 IndexedDB 中的来源原件和媒体原件；这些内容需要另行保管。
