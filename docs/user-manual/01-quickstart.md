# 快速开始

目标是让你几分钟内跑出第一段冒险。总共三步：**配好 AI → 选一个世界 → 开始冒险**。

## 第一步：配置 AI

AI 负责主持游戏和帮你写作。**默认已经配好**：内置一条 MiniMax，Key 由服务器提供，不用填任何东西。

1. 点右上角的 **设置**
2. 切到 **AI 配置** 标签
3. **文本模型** 默认选中内置 **MiniMax**，模型 `MiniMax-Text-01`，显示「已由服务器配置」——不用动
4. 点 **测试连通性**（可选），看到"连接成功"就说明可用
5. 关闭设置

> 想用自己平台的模型？在 AI 配置里点「添加模型配置」，新增一条你自己的配置（Key 存浏览器本地）。内置 MiniMax 的 Key 由服务器持有，你的浏览器永不接触。

## 第二步：选一个世界

回到欢迎页，点 **选择世界**（内置 MiniMax 默认可用；如果你关掉了内置模型，欢迎页会引导你配置）。

- 第一次进来没有世界书，先在 **快速导入** 里挑一个种子世界：
  - `边境王国 · 雾潮暮湾`
  - `都市异闻 · 北岸旧档`
  - `近未来殖民地 · 赫利俄斯`
- 导入后回到体验页，选中这个世界。

> 想搭自己的世界？见 [世界书与设定](./03-worldbook.md)。

## 第三步：开始冒险

在体验页选中世界后，点 **进入这个世界**。

AI 会基于世界生成一段开场白。然后你在输入框里输入行动，回车即可：

```
我环顾四周，看看有什么能用的东西
```

AI 接着往下写，右边的状态栏会实时更新你的体力、心情、金钱等。到这里就完整跑通了。
