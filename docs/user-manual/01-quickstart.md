# 快速开始

Pinax 默认从写作开始。第一次打开首页，只需要在下面两种方式里选一种；世界书和 AI 都不是前置条件。

## 从空白开始

1. 在首页点 **开始写作**。
2. 填一个书名，点 **创建并开始写**。简介和世界书都可以以后再补。
3. Pinax 会自动建立“第一章”并把光标放进正文，直接开始写即可。正文会自动保存在当前浏览器。

从首页进入的新建或导入流程，稿面标题下会显示一条可关闭的首次创作指引。它一次只提示当前下一步：先落正文，再建一个关键人物、安排当前场，最后打开推演；完成一步后会按实际书稿状态继续，不会盖住正文，也不会直接修改作品。发起推演之后，指引会挪到推演面板顶部，按真实进度提示“等待回应 / 可写成试稿 / 试稿仍可修改”，直到你采纳试稿或主动关闭。关闭后不会自动再弹；想再看一次，用 **更多菜单 → 继续创作指引**。

写到需要帮助时，再从右栏打开批注、设定、推演或助手。AI 生成的内容不会直接替你改正文，先看过，再决定是否采用。

## 回到上次的书稿

已经有作品时，首页会把最近一本书放在最前面：点 **书名** 直接回到那本书继续写；“另起一本”和“导入已有书稿”仍在下方。手机上不用滚动，第一屏就能点到。

## 带入已有书稿

首页点 **导入已有书稿**，或在创作页的空状态 / “更多”菜单选择 **导入 TXT / Markdown**。

导入分三步：

1. 选择一个 `.txt`、`.md` 或 `.markdown` 文件，最大 5 MB。Pinax 会自动识别 UTF-8、GB18030、Big5 和 UTF-16；识别不准时，展开 **“识别不对？调整编码”** 手动更换。
2. 预览识别结果，确认书名和章名；可以按标题自动拆章，也可以整篇作为一章。你手动改过的书名不会被重新识别覆盖；手改的章名只要章节内容对应关系还在就会保留，换了拆分方式时会明确提示哪些没保留，并可一键撤销。
3. 点 **创建书稿**。Pinax 会新建一本书，不覆盖已有书稿，然后直接打开第一章。存储空间不足等失败会直接显示在弹窗里，预览保留，可以重试。

选择文件和预览都不会写入；只有最后确认时才会创建书稿。Markdown 的一级、二级标题和常见的“第一章 / 序章 / 后记”等中文标题可以用于拆章；识别不合适时，选择“整篇作为一章”即可。

第一次在右栏新建人物或设定时，Pinax 会自动为当前书稿建立并关联资料库。已有资料库仍可以从“关联已有资料库”手动选择。

## 保存失败时怎么办

正文自动保存失败时，顶栏下方会出现一条自救提示，你的输入都还在稿面上。可以 **重试保存**、**导出当前正文**（把此刻稿面的文字先导出保底，包含尚未保存的修改），或打开 **查看恢复稿** 选择之前的恢复副本。保存恢复正常后提示会自动消失。

## 先知道数据放在哪里

作品保存在当前浏览器，不会自动同步到其他浏览器或设备。无痕窗口、清除浏览数据或浏览器存储异常都可能让本地内容消失。

写作一段时间后，打开首页的 **备份**，或从创作页 **更多菜单 → 备份与恢复** 进入 **导出本地作品备份**，把 JSON 文件保存到可靠的位置。作品备份默认不包含你自己填写的模型 API Key，也不包含 IndexedDB 中的来源原件和媒体原件；这些内容需要另行保管。

导入备份前，Pinax 会先展示这份备份的生成时间和包含的书稿，并说明将新增、覆盖多少项数据，确认后才会写入。恢复成功后可以从提示直接回到对应书稿；单本书的备份直达该书，多本书的备份回到作品列表。
