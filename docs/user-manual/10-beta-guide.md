# Web 内测说明

这轮内测要确认一件事：作者能否在网页里顺畅完成一次从进入、写作、试演到带走作品的完整过程。它不是功能清单验收，也不要求你先学会全部工具。

## 建议用什么环境

- 优先使用桌面版 Chrome 或 Edge 的普通窗口。
- 同一轮测试尽量不要中途更换浏览器或设备。
- 不要使用无痕窗口；无痕窗口关闭后，本地作品可能被清除。
- 手机可以检查阅读和临时修改，但中文输入法、软键盘及 Safari / 微信浏览器尚未完成系统性验收。

## 一次 15 分钟体验任务

请按自然习惯完成，不必为了“测全功能”到处点：

1. 从首页新建一本书，或导入一份 TXT / Markdown 旧稿。
2. 新写或修改约 300 字，切换一次章节，再刷新网页，确认正文仍在。
3. 在右栏补一项人物、地点或大纲资料。
4. 使用一次推演：安排行动，读人物回应，换一种走法或查看试稿。
5. 回到正文完成修改，最后到 **备份 → 导出本地作品备份**。

如果某一步让你停下来猜“接下来该点哪里”，这本身就是重要反馈，不必绕过去。

## 怎么反馈最有用

把下面五项发给邀请你参加内测的人即可：

```text
我原本想做：
我实际做了：
我预期看到：
实际发生了：
刷新后作品是否还在：是 / 否 / 没检查
```

最好再附一张截图。若问题难以复现，可在 **设置 → 存储 → 导出诊断信息** 下载低敏 JSON 一并发送。诊断文件只包含浏览器环境、视口、存储用量和书稿/章节数量，不含正文、标题、项目 ID、提示词、模型回复或 API Key；发送前仍可用文本编辑器自行检查。

请不要发送模型密钥。除非你明确愿意，也不需要把完整书稿交给测试人员。

## 数据与恢复

作品保存在当前浏览器，不会自动同步到云端。建议每次较长测试结束后都导出一次作品备份。

- 刷新或普通关闭页面后，正文应当仍在。
- 换浏览器、换设备、清除网站数据前，必须先导出备份。
- JSON 作品备份默认不含模型 Key，也不含 IndexedDB 中的来源文件和媒体原件。
- 导入备份会先展示新增、覆盖与跳过项目，确认前不会写入。

若页面异常，先不要清理浏览器数据：依次尝试刷新、导出作品备份、导出诊断信息，再联系邀请人。

## 当前明确不要求测试

- 多人协作和公开分享
- 漫画、视频及完整媒体资产迁移
- 云同步、账号系统与多设备实时一致
- 地图大型生成压力
- Electron 桌面版安装

这一轮的产品承诺是“本地优先的 AI 小说写作与实验性推演”，未列入承诺的外围功能不影响本轮是否可用。
