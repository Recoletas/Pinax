# Pinax 使用指南

Pinax 是以作者为中心的 AI 辅助创作工具。当前核心入口是 **创作 `/authoring`**，可以新建书稿直接写，不必先配置世界书或进行冒险。

它提供这些可组合的工作方式：

- **冒险**：选一本世界书，AI 当主持，你输入行动，剧情继续往下走
- **写作**：管理章节、构思和大纲，并排查资料或写副稿；需要帮助时生成可编辑试稿，由你决定采用或放弃
- **搭世界**：用结构化设定维护人物、地点、规则，AI 按这套设定创作
- **做分镜**：把素材、镜头、章节片段放到卡片画布上连成时间轴，还能生成配图和视频

本指南只讲"怎么用"，不涉及部署和技术实现。

> 当前默认从创作首页进入 `/authoring`；`/writing` 只保留兼容重定向。体验模式仍可使用，但不是开始写作的前置步骤。

## 可选的素材转写流程

```text
选一个世界
  -> 进去冒险
  -> 沉淀剧情日志和素材
  -> 写成作品
  -> 整理成分镜或继续扩展世界
```

这条流程是可选的；你也可以从已有小说或空白稿件开始创作。
