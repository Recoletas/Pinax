# Pinax 使用指南

欢迎来到 Pinax —— 一个 AI 辅助的小说创作与文字冒险平台。在这套平台上，你可以：

- **进入一个世界冒险**：选一个世界书，AI 当主持，你输入行动，剧情继续往前走
- **把冒险写成作品**：冒险中产生的金句、关键事件、角色关系会沉淀成素材，方便你整理成小说
- **搭自己的世界**：用结构化设定维护人物、地点、规则，让 AI 在你的世界观里创作
- **可视化整理剧情**：素材、镜头、章节片段在卡片画布上连成时间轴，还能生成配图和视频

本指南面向**使用平台的你**，只讲"怎么用"，不讲部署和技术实现。
