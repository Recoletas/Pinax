# Pinax 使用指南

Pinax 用来写小说、整理人物和设定，也可以用 AI 改稿、问答和推演情节。正文编辑、批注和资料整理不需要模型；请求 AI 时才需要可用的模型配置。

## 几个容易混淆的名称

- **正文**：章节里正在编辑的稿件。AI 候选需要采用后才写入。
- **世界书**：一本作品关联的人物、地点、规则等设定资料。
- **当前场**：落笔处这一场戏的时间、地点和在场人物。
- **构思 / 速记**：还没确定写入章节的想法或片段。
- **正文版本**：较早的稿件记录，从“批注 → 版本”或章节菜单“历史版本”查看。
- **记忆与历史**：故事事实、证据和修订记录，入口在设置里。

## 跑团和视听工具

[跑团](./02-experience.md)按角色行动推进冒险会话；正文旁的推演用于尝试某一段情节。[视频与编导助手](./06-storyboard.md)和[漫画](./09-comics.md)处理分镜与画面制作。各页分别说明入口、所需模型和导出方式。

## 稿件存在哪里

稿件保存在当前网址的浏览器工作区。换网址、浏览器或设备后，不会自动带过去；迁移前在原环境导出完整工作区 ZIP。具体范围和恢复步骤见[设置详解](./07-settings.md)。

使用 AI 时，完成任务所需的正文和资料会发送到所选模型渠道。自定义模型密钥不包含在作品备份里，需要另外保管。
