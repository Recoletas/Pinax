# Pinax 使用指南

Pinax 把书稿、人物设定、参考资料和助手放在一个工作区里。先打开作品，再从左侧目录选择要写或要看的内容。

应用内文档沿用工作区左栏：指南图标打开章节列表，可按标题或说明查找；大纲图标切换到“本页内容”，点击小节跳到对应段落。手机从顶部目录图标展开左栏。文章末尾可切换前后章节。

## 先分清这几处

- **左侧目录**整理本书内容，默认分为正文、构思、设定、资料和素材。文件夹里的位置不决定章节出版顺序。
- **中央标签**打开具体内容：章节用写作编辑器，人物用设定编辑器，来源用阅读器。首页的最近打开只列作品。
- **右侧工具**跟随当前工作台。写作时可打开助手、推演、批注等；编辑设定时可查看同类、表格、关系和管理。图标悬停或获得键盘焦点时显示名称。
- **设置**管理外观、模型和备份；人物、地点等创作内容在设定里编辑。

正文、设定和导入资料保存在当前浏览器。没有自动跨设备同步；换设备或网址前，请导出[完整工作区 ZIP](./07-settings.md#备份与恢复)。
