# Pinax 使用指南

Pinax 以核心工作台为中心，提供基础写作和通用 AI；关联世界书后，进一步使用本书的人物、规则和历史开展特色 AI 创作。

## 基础流程

[新建或导入书稿](./01-quickstart.md) → 在[核心工作台](./05-writing.md)写作、整理章节，按需使用批注和通用 AI → 修改、保存与导出。纯写作无需配置模型；通用 AI 需要可用渠道，但不要求先关联世界书。

## 世界书增强流程

从[资料页](./03-worldbook.md)导入或添加来源 → 整理各项设定 → 关联当前书稿 → 在工作台使用参考本书人物、地点、规则和历史的查询、人物回应与推演。

高级条目用于精细管理，地图用于补充地理关系，目前还没有完全融入整体流程。资料可以边写边补，不需要一次建完。

## 扩展流程

[跑团](./02-experience.md)在现有体验页中进行，围绕角色行动和回合回应推进；工作台的推演则服务于正文创作。[漫画](./09-comics.md)和[视频与编导助手](./06-storyboard.md)是边缘扩展，可以在需要视听表达时探索。

> 作品主要保存在当前网址、当前浏览器中，不会自动跨设备同步。改用新网址、浏览器或设备之前，先在旧环境导出备份。新网址没有显示作品，不一定代表原稿已删除。

## 按需查阅

- 从空白开始或导入 TXT / Markdown → [快速开始](./01-quickstart.md)
- 在当前书稿里添加人物、地点或规则 → [世界书与设定](./03-worldbook.md)
- 批注一段文字、尝试另一种写法或恢复旧稿 → [创作与写作](./05-writing.md)
- 切换日间/夜间、调整排版或导出 ZIP / JSON → [设置详解](./07-settings.md)
- 页面异常、找不到作品、AI 连不上 → [常见问题](./08-faq.md)
- 想跑团 → [跑团](./02-experience.md)；需要漫画或视频 → 从“视听扩展”进入

本指南只说明当前可用操作。部署、架构、测试门禁和开发计划在[工程文档](../README.md)中维护。
