# 创作与写作

**创作**（`/authoring`）是 Pinax 的主工作区：左侧管理章节，中间写正文，右侧按需打开批注、大纲、角色、设定、现场、推演、助手和历史。

## 建立或导入书稿

- **新建书稿**：首页的“开始写作”会直接打开新建窗口。只填书名即可，Pinax 会自动建立“第一章”并把光标放进正文；简介和世界书可稍后补充。
- **导入 TXT / Markdown**：从创作页空状态或“更多”菜单进入。先预览拆章结果，确认后新建一本书，不覆盖已有内容。
- **继续写**：首页最多显示三本最近使用的书稿，点击即可回到对应项目。

导入支持 UTF-8、GB18030、Big5、UTF-16 的 TXT / Markdown 文件，最大 5 MB。低置信度时可以在预览页切换编码；可以识别 Markdown 标题与常见中文章名，也可以强制整篇作为一章。导入后仍可在左栏继续改章名、增删章节和排序。

## 正文与资料

正文会自动保存；正常刷新、关页或移动端切到后台前，Pinax 也会尝试立刻保存尚在等待中的输入。浏览器进程被系统强制结束时仍可能来不及执行，因此长时间写作后仍应导出备份。左栏用于书稿、卷和章节；右栏是按需展开的资料与工具，不要求写作者离开稿面：

- **批注**：记录针对具体文字的问题与修改意见。
- **大纲 / 角色 / 设定 / 现场**：查看或编辑当前写作所需资料。
- **推演**：安排一次人物行动，连续查看回应、另走一条路线并对照；满意后再把试稿带回正文。
- **助手 / 校对 / 查找**：处理局部写作任务和文本检查。
- **历史**：查看可恢复的正文版本。

批注是在现有正文上留下意见；推演是在不改正文的前提下试走未来。两者不会互相替代。

当前书稿还没有资料库时，第一次点击“新建人物”或“新建设定”会自动建立并关联一份随书资料库，不需要先离开正文配置世界书。

## 使用 AI

可以先写、之后再配置 AI。需要生成时，从设置里选择内置渠道或添加自己的模型配置。生成结果是建议或可编辑试稿，只有作者明确采用时才进入正文。

如果使用推演，推荐的最短流程是：

1. 写清当前场的人物、地点或眼前局面。
2. 在右栏安排一个具体行动。
3. 连续推进一两步，或从分歧处换一种走法。
4. 对照后查看试稿，在正文中修改并决定是否保留。

## 保存与带走

浏览器会保存当前作品，但不会自动跨设备同步。定期在 **设置 → 存储** 导出本地作品备份；换浏览器前先导出，在新浏览器中预览并确认导入。

作品备份默认不含模型 API Key，也不含 IndexedDB 中的来源或媒体原件。特别重要的正文还可以单独导出章节或整本书，形成第二份可直接阅读的副本。
