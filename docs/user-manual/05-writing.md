# 创作与写作

打开作品后，左边是章节和构思，中央是编辑区，最右侧图标栏用于打开批注、助手、推演等工具。图标看不清时，把鼠标停在上面查看名称。

![工作台的章节列表、正文和右侧工具面板](../screenshots/user-guide-20260924/02-workbench.png)

## 章节、构思和速记

点击左侧章名打开正文，点击卷名展开或收起章节。“新建章”在当前作品中增加章节；“新建书”会开始另一部作品。章节菜单里可以重命名，也可以打开“历史版本”。

还没决定放在哪一章的片段，可以先写在“构思”里。打开一条速记后，点击稿面顶部标题即可修改；按 Enter 或点到标题外保存，按 Esc 取消本次改名。标题不能为空。改名只改变速记名称，不会改章节名。

“大纲”用于记录章节目标、冲突和转折，正文仍从章节列表打开。写在大纲或速记里的文字不会自动插入章节。

## 正文编辑和排版

点击正文输入，修改会自动保存。查看编辑区的保存状态；出现“已保存”才表示本次更改已写入当前浏览器。保存失败时先复制文字或导出当前正文，处理方法见[常见问题](./08-faq.md)。

| 入口 | 用途 |
| --- | --- |
| 撤销 / 重做 | 撤回或重做正文编辑 |
| 排版 | 调字体、字号、缩进、行距和文本块边界显示 |
| 快捷词 | 管理写作时常用的表达 |
| 取名 | 选择名称候选并插入文字；人物资料需要另建 |
| 专注 | 收起周边工具，按 Esc 返回 |
| 校对 | 查看语言检查建议，再决定怎样修改 |
| 查找 | 选择搜索范围，定位正文或资料中的内容 |

文本块边界用于区分编辑单元，开关边界不会向稿件添加符号。字/词数、字符数也不是模型 token 数；同一段文字在不同软件中的统计可能略有差别。

## 批注和局部改写

![批注与其对应的正文选区](../screenshots/user-guide-20260924/03-annotations.png)

1. 拖选需要处理的原文，在浮条里点“批注”。
2. 写清想改什么、要保留什么，再点“添加”。例如：“把解释改成对话，但保留她尚不知道钥匙被换的设定。”
3. 批注会列在右侧；“编辑”修改意见，“删除”移除意见，都不会直接改原句。
4. 点“按批注改写”请求 AI 候选。检查候选后再采用；也可以放弃候选，保留原文。

批注可以先记着，以后再改。生成期间若原句已经变化，旧候选可能不再对应当前位置；重新选中要改的文字再生成，别把过期候选直接粘回。

选区浮条没出现时，先关闭正在操作的查找或校对面板，回正文重新拖选。不要在右侧回答、预览文本或章名上选字来添加正文批注。仍不出现时，按[常见问题](./08-faq.md)记录复现步骤。

## 助手：构思、查阅资料和检查文稿

点顶部“助手”进入完整页面，点“返回工作台”继续写作。边写边问时打开右侧“助手”，侧栏中的“完整助手”可以展开同一对话。切换展示会保留草稿和正在阅读的位置，不会重新发送问题。

章节栏和完整助手左侧都有“正文 / 助手 / 设定 / 资料”，切换时仍属于当前作品。助手中的“正文”下方显示当前章名，点它返回文稿。设定和资料页右上角也可直接回到正文或助手。手机上点顶部导航按钮展开。提问列表可以单独滚动，正在查看的提问会高亮；点一条提问回看对应问答，不会重新发送。检查进行中需要先停止检查再跳回对话。查询、检查或改写进行中，设定和资料入口会暂时禁用，避免离页中断任务。

侧栏顶部可以打开完整助手或资料；有对话后，同一行还会显示搜索和提问历史。搜索只筛选当前问答，历史中的提问会填回输入框，修改后再发送。

空白作品可以点“让助手帮我开始”。也可以在新建作品时选择“和助手构思”，书名稍后再定。页面上的构思提示只会填入问题草稿，修改后点发送；也可以直接写作。

默认是“讨论故事”，用于聊人物、情节和写法，不会自动读取正文。要讨论具体片段，可以把文字附在问题里。要核对本书已有内容，在输入框里切到“查阅资料”，或从“＋”中选择它，再写问题并发送。

输入框中的“＋”还提供“检查文稿”和“生成插图”。正文为空时不能检查文稿。

| 要处理的问题 | 建议入口与问法 |
| --- | --- |
| 讨论情节和写法 | 讨论故事：“我想让两人互相试探，但还不摊牌。可以怎样推进？” |
| 核对前文或设定 | 查阅资料：“小莲在哪一段说过自己的来历？请列出处。” |
| 检查正文中的问题 | ＋ → 检查文稿：选定范围，写清这次要检查的问题，例如重复描写或衔接不顺 |

“查阅资料”查询当前作品已接入的正文、设定等内容。找到依据时，回答会附上实际引用的资料。直接点引用标题可在助手里预览片段，再点“打开原文”跳到对应内容。

查询范围是当前作品，不表示模型已逐字读完所有章节；找不到资料时，缩小问题、补上人物名或事件名后再问。资料页导入的原始文件目前尚未接入助手检索，需要核对文件时请到资料页打开原件。这里也不能用来搜索网页。

每部作品的对话和输入草稿分别保存在当前浏览器。切书后显示对应作品的对话；刷新不会自动重发问题。生成期间刷新会中断请求，需要时自行重试。

### 写作与修改

在输入框的任务菜单选择 **写作与修改**。用 **参考与技法**选正文或设定，再选需要的技法；也可以输入 `@` 搜索参考，按方向键选择，按 Enter 或 Tab 确认。确认参考不会发送问题。

候选留在助手里。检查后点 **加入生成时的章节**；先前切到了别章时，要回到原章再采纳。失败或中断的回答不能直接加入正文。保存失败时回答仍保留，排除存储问题后再点采纳；采纳前的正文版本会留在历史中。

继续发消息会沿当前任务追问；**重新开始任务**保留对话记录，并重新建立任务。问答历史中的 **新对话**用于另开话题，作品导航可切回旧对话。刷新不会自动运行任务，下次发消息才尝试续接。

这些工具需要服务器运行时。提示暂不可用时，可继续使用讨论故事和查阅资料。参考与技法中的体验开关默认关闭；开启后也不会绕过严格推演的发布前检查。工具检索只覆盖本次加载的有限片段，原始资料文件和外部数据库尚未接到这个入口。

“检查文稿”打开审稿面板：选择范围并说明要求，检查建议或改写候选后再采用。采用前不会改动正文；采用后可通过审稿中的撤销入口撤回。“生成插图”需要图像渠道，文本模型连接成功不代表生图也能用。

## 生成插图

在正文选中一段，或把光标放进要配图的文本块，再点 **生图**。先核对来源，编辑画面描述，选择模型、比例和张数后生成；也可以先用“整理画面描述”从原文得到草稿，检查后再使用。

左侧是生成参数，右侧看当前图和本书候选。风格选项只补充描述，不会自行生成图片。每张成功结果会自动存入生图历史；**保存为素材**会另建素材条目，**插入正文**则把选中的图片放在原文本块后。这两个动作都需要你选择。

生成开始后，作品、章节和原文位置会固定。原文已经改过或切到另一部作品时，旧结果仍可查看、下载和保存到原书素材，不能直接插进新的位置。停止保留已完成图片；保存失败时用 **重试保存**，不要再生成一遍。

使用自配 ComfyUI 时，“停止”会停止等待和接收结果；已经提交到 ComfyUI 的后台任务可能继续运行，需要在 ComfyUI 中处理。

内置 MiniMax 可使用一张人物参考图（JPG/PNG，小于 10 MB）；参考的是人物外观，不保证逐格身份完全一致，也不等于支持蒙版或构图编辑。其他模型可用的参考数量随配置变化。图片已插入正文、存为素材或被漫画引用时，不能从生图历史删掉对应文件。

## 推演：从行动到正文试稿

![推演面板中的行动和本次条件，尚未发送](../screenshots/user-guide-20260924/04-rehearsal.png)

### 开始一条走法

1. 把光标放到想接着写的位置，打开右侧“推演”，点“从当前段落开始”。
2. 如果先出现现场确认，核对人物和地点。选入需要的项后保存；本次不调整时可点“暂不调整，直接推演”。
3. 在“让人物…”中写具体行动，例如“他暂时不解释来历，反问她为何独自进城”。如果出现行动者或动作对象选项，选清是谁对谁做什么。
4. “补充本次条件”用于这条走法的假设，例如“她尚不知道他的姓名”。它不会替你修改世界书。
5. 点“试演”，等回应出现。生成中可以点“停止”。

### 继续或换路

根据上一条回应再写下一步行动。想换一个选择，可以从较早步骤换路。每条走法最多试演四步；达到上限后可以换路，或把当前走法写成试稿。

若面板提示起点已变化，点“重新确定起点”。这常见于正文或相关资料已经改过，原走法仍引用旧内容的情况。角色已经完成的动作不应再发生一次；如果生成重复了，先别采用，记录对应步骤和本次行动后重试。

### 把结果用于正文

有试演步骤后，点“写成试稿”。这是一次新的生成请求：把当前走法整理成放在正文落笔处的候选，不是直接把面板文字粘贴进章节。

检查试稿后再采用。已经有待处理试稿时，先点“查看试稿”，处理已有候选，再生成另一份；不要反复点击生成来解决保存失败。面板回应、正文试稿和已采用正文是三个不同阶段。

试演中的有用内容也可以手动复制整理。尚未采用的结果不要只靠页面保留，离开或刷新前先留副本。

## 当前场：地点和人物要保存后才生效

![当前场面板中的时间信息](../screenshots/user-guide-20260924/05-current-scene.png)

打开“现场 → 调整当前场”。这里填写落笔处的时间、地点和在场人物，保存的是这一场的状态。

“从正文识别”区域会根据附近文字提出候选；点“重新识别”可以再查一次。人物候选点“选入在场人物”，地点候选点“设为当前地点”，最后点底部“保存当前场”。只点候选、没有保存，仍是草稿；“取消”放弃本次调整，“撤销上次保存”在可用时撤回上一次场景保存。

当前识别主要匹配已关联世界书里的名称和关键词：

- 世界书中没有的人物，不会因为正文出现一个名字就自动建档。
- 提到一个地点，不一定表示当前就在这里；回忆、转述和否定句都需要自己判断。
- “附近没有待确认的人物或地点”只表示这次没找到新候选，不表示这一场没有人物。
- 普通输入不会每敲一个字就更新在场名单。准备推演时可能先提示确认；需要立刻核对时手动打开现场。

修改人物或地点资料本身，去“角色”或“设定”；调整这一场谁在场，留在“现场”。

## 正文版本和记忆记录去哪里看

| 要找的内容 | 入口 |
| --- | --- |
| 这一章以前写过的文字 | 右侧“批注 → 版本”，或左侧章节菜单“历史版本” |
| 故事事实、AI 提取候选和记忆修订 | “设置 → 记忆与历史”，或工作台右侧助手顶部的“记忆与历史” |
| 人物、地点、规则的设定内容 | 工作台“角色 / 设定”及关联世界书 |

恢复正文前，先比较版本时间和内容，给现在的稿件留一份副本。记忆记录不能代替正文备份。

## 英文、混合语言和备份

作品语言在书稿侧栏设置，影响支持该设置的后续 AI 任务，不会翻译已有正文。界面语言在“设置 → 外观”切换，两者分开。

TXT / Markdown 导入可识别 `Chapter 1`、`CHAPTER IV: The Door`、`Prologue`、`Epilogue` 和 Markdown 标题；确认前看拆章预览。字/词统计按汉字及其他 Unicode 词计算，英文词内的撇号连接，连字符分开。

换浏览器、设备或网址前，使用“设置 → 备份与恢复”导出完整工作区 ZIP。导出正文只带走文字，轻量 JSON 也不能代替资料原件、媒体和记忆归档的完整备份。见[设置详解](./07-settings.md)。
