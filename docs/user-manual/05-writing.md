# 写作

**写作**（`/writing`）是小说创作的主界面：左边书 / 章管理，中间编辑器，右边 AI 工具栏。

## 书与章管理

- **新建书**：点「+ 新书」，填标题和描述
- **新建章**：在书下点「+ 新章」
- 左侧书架显示每章字数，可以**拖拽排序**
- 书的列表可以下拉切换

## 编辑器

编辑器支持三种模式，顶部切换：

- **WYSIWYG**：所见即所得
- **Markdown**：直接写 Markdown 源码
- **预览**：渲染后的效果

编辑器里有**查找替换**，也能选中一段文字 **收为素材**（进 [素材库](./04-materials.md)）。

## AI 写作助手

右侧工具栏提供了 8 个动作：

| 动作 | 干什么 |
| --- | --- |
| 改写选区 | 换一种表达 / 风格重写选中文字 |
| 扩写选区 | 把一段铺得更细 |
| 压缩选区 | 把冗长段落压短 |
| 修正当前段落 | 修润色，保持原意 |
| 补强段落衔接 | 让段落之间过渡更顺 |
| 自动收线 | 帮当前章节收尾 |
| 章节体检 | 检查一致性 / 逻辑问题 |
| 轻续一句 | AI 接着往下写一句 |

> **续写参考**：可以从素材库把某条素材设为"续写上下文"，AI 续写时会参考它。**章节纲要**也会参与续写。

## 顾问

章节旁的 **顾问** 按钮，对当前内容做一次"体检"，返回三类提示：

- **严重问题**：逻辑冲突、设定违反
- **值得回头看看**：节奏、人物一致性
- **可选建议**：润色、扩展

## 导出分镜

整章写完后，可以 **导出章节分镜**：AI 把章节拆成一组镜头（场景描述 + 镜头语言），存成分镜版本。之后到 [卡片画布](./06-storyboard.md) 里排时间轴、生图生视频。

## 完整流程

1. 新建书 → 新建章
2. 写个开头，选中后点 **扩写** 或 **续写**，AI 接着铺
3. 不满意就 **改写**，换一种风格
4. 写完整章，选全文 **导出分镜**
5. 到画布排时间轴
