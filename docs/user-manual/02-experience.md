# 体验模式

体验页（`/experience`）是冒险的主战场：AI 当主持，你在一个世界里一步步推进剧情。

## 聊天

- 底部输入框输入行动，回车发送，AI 接着往下写
- 顶部可以调**阅读节奏**（紧凑 / 标准 / 舒展），控制 AI 回复的详略
- 右上角有**现场索引**，展开后能看当前的人物、地点、事件、时间
- 顶部的 **会话** 能切换 / 新建 / 删除会话——会话就是一段冒险的存档，世界绑定在会话上

## 状态栏

右侧会显示当前角色的状态：

| 状态 | 含义 |
| --- | --- |
| 体力 | 生命值 / 精力 |
| 心情 | 情绪状态 |
| 金钱 | 手头的钱 |
| 等级 / 经验 | 成长进度 |

## 机制按钮

遇到"战斗 / 交易 / 接任务 / 对话"这类需要走一套固定流程的场景时，页面右下角会出现对应的机制按钮（带 ⚡ 通知）：

- **战斗**：攻击 / 防御 / 技能 / 逃跑
- **交易**：购买物品
- **任务**：接受 / 暂时忽略
- **对话**：选项列表

点哪个，AI 就按哪个模式来写，不用纯靠自然语言硬描述。

## 里程碑

剧情推进到关键节点（解锁新地点、新角色登场、时间跃迁）时，会弹出**里程碑**提示卡，你可以选择接受（写入状态栏）或忽略。

## 记忆

AI 在冒险中会自动识别"值得长期记住"的信息——比如你不喜欢冗长描述、偏好短句。这些会进左下角的 **记忆** 面板，分为**待确认 / 已确认 / 已归档**三类：

- **采纳**：这条成为跨会话的偏好，以后 AI 都记得
- **拒绝**：留在本地，不再提示
- **同步**：如果你配置了记忆服务，可以同步过去

> 记忆怎么配、要不要配：见 [设置详解](./07-settings.md)。

## 换世界

世界是绑定在**会话**上的。要换一个世界：

1. 点侧边栏的 **选择世界**（或欢迎页的"选择世界"入口）
2. 回到体验页，顶部会话切换
3. 想开新世界就新建一个会话

## 联机

体验页激活时，顶栏会出现 **联机** 入口（也能从侧边栏进）。联机把当前冒险变成一个小房间：

- 进入大厅后填昵称 + 房间码（留空创建新房间），生成 8 位房间码
- 把房间码发给朋友，就能在同一段冒险里共同创作
- 房主有权威：成员可以提议动作，房主决定执行哪一个

> 联机房间目前是**人类玩家**一起玩，没有 AI 协作者。

## 速记与素材

冒险中的精彩段落可以：

- **收为素材**：把当前或选中的文字存进素材库
- **速记**：临时记一笔，之后整理

素材后续会流向 [画布](./06-storyboard.md) 或 [写作](./05-writing.md)。
