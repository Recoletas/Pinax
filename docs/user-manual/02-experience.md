# 跑团

从**体验**工作区进入跑团。选择会话和开场后，在输入框描述角色行动，阅读回应，再进行下一步。想把某段记录用于小说时，可以先“收为素材”，再回写作工作台整理。

![体验页同时显示记录流、开场场景、本场玩法和现场索引](../screenshots/user-guide-20260924/11-roleplay.png)

## 从本地演示开始

没有 AI 配置时，体验页提供**本地演示**：按钮推进的是预设示例，不调用模型。它适合先了解记录流、开场和右侧现场索引；示例不能代表完整的 AI 主持或联机体验。

正式开始时，可在当前冒险中选择一个开场场景，或通过会话选择器建立/切换会话并选择世界书。会话用于区分不同冒险进度；开始前确认当前世界和角色。

## 选择本场玩法

- **自由叙事**：不掷骰，直接用自然语言描述行动，由故事回应继续。
- **轻规则 2d6**：需要判定的行动会先显示检定信息；玩家确认后掷骰并按规则形成结果，再请求叙事回应。

可以为本场设定一个可选目标。规则模式中的角色属性修正、线索检定、资源和已确认变化应以界面当前记录为准；不要把模型文字中提到的物品或事实当作已经入账，只有明确确认的状态变化才会成为正式记录。

## 写一条行动

在下方输入框说明角色具体想做什么，例如“我先检查门锁，再听听屋里有没有动静”。清楚表达行动比只写“继续”更容易得到可判断的回应。规则模式下，若行动触发检定，先查看属性、修正和规则说明，再确认；如果生成失败，可在待回应条中重试或放弃。重试沿用已确认的骰点，不会暗中重新掷骰。

继续阅读记录流、行动、选择和系统回应。右侧**现场索引**按需展开时间、人物、地点和事件；点开条目查看详情，不需要把所有档案同时铺满屏幕。

## 场景冒险与主持

部分场景提供出口、线索行动和角色资源。选择出口切换地点；检查线索会先准备检定，确认后才结算。发现的线索和近期事件显示在场景记录中。若开启受限主持功能，可让主持流程推进有限拍数并暂停/继续；每一拍仍受现有场景和故事事实限制。自动伙伴建议可采纳或忽略。

这些具体机制只在场景提供时出现，不是每次体验都必须使用。查看当前场景、角色和规则，再决定是否启用轻规则。

## 会话、记录与素材

会话承载一次冒险及其场景进度。界面提供会话切换和相关记录；导出的公开记录与作者记录用途不同，导出前检查其中是否包含需要保密的内容。事件归档状态若显示待重试，说明尚未成功归档，不要把它当成已经写入正式记忆。

有用的描写、对话或发现可以用**收为素材**保存；**速记**适合暂存想法，之后从[素材库](./04-materials.md)筛选、编辑或转为其他创作内容。跑团记录不会自动成为小说正文，也不会因出现在对话中就自动成为已确认世界设定。

## 联机

联机入口可创建或加入房间，具体房间权限和主持操作以当前页面为准。联机能力仍在持续完善，开始前先核对参与者、房间状态及作品数据范围。不要将多人房间误认为云端作品同步或作品自动共享。

## 与写作工作台的区别

| 工作台推演 | 独立跑团 |
| --- | --- |
| 围绕一段正文和当前场景试走情节 | 围绕会话、角色行动和回合记录体验故事 |
| 临时候选，不直接改正文 | 记录冒险进度；规则模式可保存已确认判定与状态变化 |
| 用于作者比较写法与后果 | 用于扮演、探索和互动体验 |
