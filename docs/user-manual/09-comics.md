# 漫画

漫画目前是边缘扩展，用于按需把已有素材或分镜转成视觉表达，不是核心写作流程的必经阶段。

**漫画制作**（`/comics`）把素材 / 分镜改编成多页漫画，逐格完成构图、线稿、上色，最后导出成品。入口有两个：素材页副工作台的「漫画制作」，或侧边栏素材活动下的「漫画制作」。漫画默认归属当前作品：从首页选择一本书后进入，目录、来源与导出都只包含这本书的内容。

## 开始方式

- **新建改编**：从素材里选几张卡，AI 生成 2-3 个多页候选。每页有页级节拍和页尾钩子，对白 / 旁白和画面描述分开保存
- **新建漫画页**：跳过改编，直接做单页；空书里也可以在空态一键建立空白页，不需要先配置模型

## 页面计划

多页改编先落成**页面计划**：每页 1-8 格，可以多选素材、切换候选、展开格级节拍、建立多页制作序列。移动端一次只显示素材或计划主区。

## 页目录

进入整页制作后，左侧是**页目录**：按序列与页码稳定排序（编辑旧页不会让列表重排），每页显示真实格框缩略图，已有画面时显示该页画面。工具栏可按序列筛选；有多个序列时用「序列」下拉切换。

- 两本书各自打开漫画，互相看不到对方的页、来源与候选；共用同一本世界书也不会混页
- 早期版本遗留的**未归属旧漫画**会单独放在目录底部的隔离区，只读展示，不参与生成与导出；可以用「归入本书」显式收编

## 编辑与保存

- 页标题、画面描述、对白、旁白在失焦或换页时自动保存；输入未失焦就刷新页面，内容也会先保存再离开
- 长对白输入框自动增高，不会在框内滚动

## 生成请求的可靠性

- 双击生成只会发出一次请求；请求在途时按钮禁用
- 生成请求发出后修改了这一格：新图仍会进入这一格的候选区，但**不会自动替换**当前画面，会提示「候选未自动选用」
- 刷新或关闭页面时如果还有请求在途，重新打开会显示「**结果未知**」提示：不会自动重发，可以选择「核查结果」或明确「重新生成」
- 生成成功但图片保存失败时，可以「只重试保存」，不会再次调用模型

## 视觉圣经

改编时会把角色长相、地点、道具等设定汇成**视觉圣经**，让同一角色 / 场景跨页保持一致。视觉圣经可以增删来源、锁定不变量，并跳回 [世界书](./03-worldbook.md) / 地图 / [素材](./04-materials.md) 核对。

## 构图

整页制作区是**中央构图工作台**：

- 格框可以拆分、合并、八向拖边、调沟槽、改阅读顺序
- 画布支持**页漫 / 条漫**
- 每格可叠**人物调度框、运动向量、视觉焦点、地平线和气泡安全区**
- 右侧检查器可以用工具栏的「收起检查器」折叠，画布随之扩大

格框与沟槽会进入整页预览、单格生图比例、图片裁切和导出。

## 制作流程

按格推进。彩色路线是 `草图 -> 线稿 -> 平涂 -> 上色 -> 效果`，黑白路线是 `草图 -> 线稿 -> 网点 -> 效果`：

- 每阶段可**真实生成**、上传替换、切换候选、确认
- 支持**局部遮罩修订**（只重画某一区域），以及身份 / 服装 / 地点 / 道具 / 风格参考
- 后一阶段要求前一阶段已确认；视觉圣经或上游变化后，旧产物会失效
- 生成结果只进入「待审」候选，需要明确「确认采用」才会成为该阶段成稿

## 文字与导出

- 对白、心声、旁白、拟声支持横 / 竖排、字重、旋转、气泡尾巴
- 出版质检检查文字溢出、文字框重叠、焦点遮挡和安全区；点击质检条目可以直接跳到问题所在的格
- 整页导出 **PNG / WebP / PDF**；竖向条漫按格框边界切片。导出开始时会锁定当前页快照，导出过程中的修改不会混进文件
- 有格子缺少最终画面时，成品导出会被阻断并说明缺哪几格；此时可以导出带水印的「**分镜草稿**」

## 与画布的关系

[视频与编导助手](./06-storyboard.md) 排好的分镜镜头和素材页的素材，都可以作为漫画改编的输入。漫画页完成后可导出成品，或继续回到写作 / 素材沉淀。
