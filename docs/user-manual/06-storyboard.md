# 卡片画布

**卡片画布**（`/prose-essay`）是把故事可视化、做分镜的地方。默认进入**分镜模式**：节点（卡片）连成时间轴，可以生成配图，甚至生成一段镜头视频。

## 节点与边

- **节点**：一张卡就是一个故事片段。输入主题点「生成」，AI 产出卡片内容
- 卡片可以**拖拽**摆放，也可以**堆叠**成 pile（堆）
- **边**：节点之间用箭头连接，表示前后关系（前后镜 / continuation）
- 节点可以 **生成延伸卡片**（衍生），衍生节点带「衍生」标记
- 节点可以**转为素材节点**，或删除

## 时间轴

- 顶条有**时间轴摘要** chip
- 节点可以 **加入时间轴** / **移出时间轴**，进入时间轴后显示「镜头 #N」
- 时间轴卡片可以拖拽排序——这就是分镜的先后顺序

## 生成图片

右侧的**生图侧栏**可以用 AI 模型把当前节点 / 灵感配成图，图可以导入当前选中卡片。

模型配置在 [设置详解](./07-settings.md) 的 AI 配置里管理，不用每次重新填 Key。

## 生成视频

分镜时间轴排好后，点 **生成视频**，AI 按时间轴的镜头顺序生成一段视频（默认 MiniMax Hailuo 模型）。

## 导出

画布支持多种导出方式：

- **生成 / 更新分镜版本**：把当前画布存成分镜版本
- **导出为 Markdown / 下载分镜 Markdown**：分镜脚本
- **导出为 TXT**
- **导出完整关系网 JSON**：完整数据备份
- **导出剪辑包 ZIP**：分镜相关的打包文件

## 数据从哪来

素材库的素材可以一键送入画布（见 [素材](./04-materials.md)），写作页导出的章节分镜也会落到这里。整个链路的常见走法：

```text
素材 / 章节 -> 画布节点 -> 时间轴（镜头顺序） -> 配图 / 生成视频 -> 导出
```
