# 视频与编导助手

这里用来把故事片段整理成镜头：先把素材放进场景板，再把需要的节点加入时间轴，调整顺序和时长。生成图像或视频还需要对应的模型渠道。

![正文片段收为素材后，在画布中成为一个尚未排入时间轴的节点](../screenshots/user-guide-20260924/12-storyboard.png)

## 从一段故事开始

从正文进入：在正文选中一段 → 点 **素材** → 在素材页检查 → 点 **导当前到画布**。空白工作区可在中央输入场景，点 **拆成镜头**；也可以点左下角 **新建空白卡片**，打开 **镜头参数**，自己填写画面与动作。有节点后才展开时间轴和编导控件。带入的节点保留素材来源，方便回头核对原文。

图中素材已导入，时间轴仍为空。下一步需要选中节点，把它加入时间轴。

## 把节点整理成镜头顺序

1. 在 **场景板** 查看和选择节点；先确认它们描述的是哪一个场景、是否重复或缺少必要信息。
2. 在节点详情补充镜头意图、画面描述等内容。若要使用关系或节拍，按界面要求选中素材并建立关系，或把节点加入节拍。
3. 将需要拍摄的节点 **加入时间轴**。时间轴决定镜头顺序；场景板上的空间位置主要用于整理，不应把画布连线直接当成剪辑顺序。
4. 调整镜头顺序与时长，检查转场、对白和音效。回看原始素材，确认没有把人物动机或事实改错。

未加入时间轴的节点仍留在场景板，可以以后再处理。

## 编导顾问和生图

编导顾问可针对当前场景询问，例如“这两个镜头之间缺了什么动作？”或“观众什么时候知道门外有人？”。把回答当作待检查建议，逐项与正文和设定比对。

需要画面参考时，可从节点或工作区打开 **生图**，描述构图、人物动作和氛围，再检查候选图。生图依赖可用的图像模型渠道；生成图片是参考或候选，不会自动成为正式镜头。若要求角色外观稳定，先补充并检查人物、服装和地点参考。

## 生成视频

时间轴里有镜头后，点击顶部 **生成视频**。面板一次生成一个镜头：

1. 选择当前镜头，检查 **画面与动作**，可以直接改写。切换镜头会保留本次打开面板期间各镜头的描述草稿。
2. 选择视频模型、清晰度和时长。不同渠道支持的画幅、参考图和时长不同，按面板可用选项操作。
3. 点击 **生成当前镜头**。提交完成后可关闭面板；在同一个浏览器标签页重新打开，或刷新后再打开，会继续查询上次任务，不会自动重新生成。
4. 成功后先保存生成记录，再下载视频原件到当前浏览器。看到 **原件已保存** 后，可直接播放、下载，并随完整工作区 ZIP 备份带走。**打开原视频**仍可访问渠道提供的链接。

网络中断或查询暂时失败时，用 **继续查询** 查同一个任务。**停止等待**会停止 Pinax 跟踪；渠道可能仍在生成和计费。任务提交超时或服务重启后查不到任务时，先核对渠道记录，再决定是否重新生成。

镜头建议保存成功后才显示已应用。时间轴修改后，关闭面板再打开，会使用更新后的分镜；已提交的任务仍保留提交时的镜头与作品归属。结果链接保存失败时可以 **重试保存链接**；原件下载失败时可以重试保存原件，都不会重新生成视频。

### 找回以前生成的视频

面板下方按当前镜头列出已保存的结果，点击一项切换预览；也可以查看当时使用的画面描述。列表默认显示最近四项，更多结果可展开。切换镜头后，列表跟着切换；较早分镜版本的结果会有标记。

已保存原件的结果优先从当前浏览器播放，渠道链接过期不影响本地文件。只有链接的旧结果仍受渠道有效期限制；服务重启后也可能无法再取回原件。自动保存单个文件上限为 64 MiB，超出时请打开原视频自行下载。

清除浏览器数据会删除本地原件。需要迁移或长期保留时，下载视频或导出完整工作区 ZIP；轻量 JSON 备份不含视频文件。播放失败不会把已完成的生成任务改成失败，也不会自动重新生成。

先逐镜检查人物外观、动作和构图。单个镜头生成成功，不代表整段故事已经剪辑完成。

## 导出

使用时间轴的 **分镜稿** 下载 Markdown；页面底部的导出菜单还提供文本、分镜 JSON 与剪辑包。导出当前工作区不等同于整本书的备份；作品迁移请使用[备份与恢复](./07-settings.md)。

旧菜单中的“画布”指的也是这个工作区。
