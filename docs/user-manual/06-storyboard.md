# 视频与编导助手

这里用于把故事片段组织成分镜，检查镜头节奏，再进入视频生成或导出剪辑资料。分镜画布是其中的编辑方式；部分界面和导出文件仍沿用“画布”的旧称。

视频目前属于边缘扩展。可以从场景想法或已有素材开始，不要求先完成整部作品。

## 从故事到镜头

**场景线索或素材 → 分镜节点 → 时间轴 → 编导调整 → 视频生成或导出。**

输入场景线索生成分镜，或把素材送入分镜工作区。每个节点表达一个片段，加入时间轴后确定镜头先后；可以调整顺序，并编辑镜头时长、对白和音效。

## 编导助手

编导顾问帮助分析素材关系、镜头节奏和分镜推进方向。例如，可以询问某处转场是否突兀，或怎样用几个镜头交代一场冲突。

建议供你参考，具体镜头安排仍在分镜和时间轴中调整。生成视频之前，应检查镜头顺序与内容。

## 分镜编辑

节点可以拖动、连接、延伸或转为素材；时间轴中的镜头可以加入、移出和重新排序。需要配图时，从生图侧栏生成并选择合适的图片。

这些操作服务于镜头设计；画布的位置与关系、时间轴的镜头顺序各有用途，不要把任意节点连接直接理解为最终剪辑。

## 视频生成

时间轴有镜头后，可从 **生成视频** 进入后续生成流程。分镜有变动时，先生成或更新分镜版本，再检查视频工作区中的模型与生成内容。

发起任务需要可用的视频渠道；生成结果受模型能力影响，不保证一次生成完整且镜头完全一致的成片。模型配置见[设置详解](./07-settings.md)。

## 导出与其他去向

可以生成或更新分镜版本，下载分镜 Markdown、TXT 或剪辑包 ZIP，按当前导出面板选择所需内容。关系网 JSON 用于该工作区的数据导出，不替代整个作品的完整备份。

素材也可以进入[漫画](./09-comics.md)制作，或回到[核心工作台](./05-writing.md)继续写作。素材整理见[素材](./04-materials.md)。
