# 常见问题

按症状排障，对号入座。

## 默认（内置 MiniMax）报「服务器未配置 MINIMAX_API_KEY」

内置 MiniMax 的 Key 由**服务器**持有，不存浏览器。报这个错 = 服务器还没配 Key：

1. 找到服务器上的 `server/.env`（没有就复制 `server/.env.example` 为它）
2. 填 `MINIMAX_API_KEY=你的Key`
3. **重启服务器**后刷新页面

> 这是管理员 / 部署者要做的配置，普通用户遇到直接找平台管理员反馈即可。

## 配置了 API Key 还是报 400 / 未提供 apiKey

**最常见原因**：

1. **自定义配置没点保存**。新增模型配置后要点**保存**；切了渠道也要重新保存
2. **Key 格式不对**。MiniMax 的 Key 以 `sk-` 开头，别带多余空格
3. **换了浏览器 / 开了无痕 / 清了浏览器数据**。自定义配置存在浏览器本地，换环境就没了，重新加一次（内置 MiniMax 不受影响）

**排查**：设置 → AI 配置 → 选中你的模型配置 → 点 **测试连通性** 看报什么错。

## 模型是哪个？怎么换

- 默认是内置 **MiniMax**，模型 `MiniMax-Text-01`，开箱即用
- 换模型：设置 → AI 配置 → 点**文本模型**框 → 在列表里选另一条配置，或点「添加模型配置」新建
- 换完记得再点一次测试连通性确认

## 选 Ollama（本地）连不上

1. 本机 Ollama 跑起来了吗？
2. 模型拉了吗？（`ollama pull llama3` 之类）
3. Base URL 是 `http://localhost:11434` 吗？不要加 `/v1` 也不要加路径
4. UI 上 API Key 不能为空，随便填一串字符串即可（Ollama 不校验）

## 地图生成很慢 / 卡住

**正常范围**：

- 默认配置大概几秒
- 整块大陆这种大种子可能 10-20 秒
- 超过 30 秒基本有问题

**加速办法**：

1. 用更小的生成参数（世界地图页右上角有调参）
2. 别用特别大的种子
3. 如果完全卡死：刷新页面重新生成（不会破坏已保存的数据）

## 点 AI 按钮没反应 / 一直转圈

1. 检查设置里 Key 是否还在（换浏览器会丢）
2. 点 **测试连接** 看通不通——网络不通会一直转
3. 顾问按钮不响应：顾问是可选功能，不影响核心玩法；不需要就忽略它

## 移动端键盘遮挡输入框

1. 滚一下页面，输入框会自动浮到键盘上方
2. 暂时用横屏
3. 建议用 Chrome / Edge / Safari 主流浏览器

## 浮层打不开 / 关了弹窗页面滚不动

- F5 刷新即可
- 实在不行：先导出备份（设置 → 存储），再清浏览器数据重来

## 切换世界后旧世界的数据还在

**这是预期的**。世界书是多本共存的：切换世界只切换激活的那一本，导入过的都还在。要删某本世界书，去 **设定 → 高级设置** 的条目管理里操作。

## 内容丢了 / 想恢复

本地存储一般不会自己清，但：

- 浏览器"清除浏览数据"会清掉
- 换浏览器 / 换电脑不会自动带过去
- 清理工具可能清掉

**恢复**：如果之前导出过备份（设置 → 存储 → 导出全部备份），用 **导入备份** 恢复。**没有云同步**，多设备之间不会自动同步——请定期导出备份。

## 想换浏览器 / 换电脑

1. 旧设备：设置 → 存储 → **导出全部备份**，把 JSON 文件存好
2. 新设备：打开平台 → 设置 → 存储 → **导入备份**

## 还有问题

去找给你部署这台平台的管理员反馈。反馈时尽量带上：什么操作、看到什么报错、用的什么浏览器。
