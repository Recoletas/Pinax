# 常见问题

先按症状处理。涉及正文异常时，原则始终是：**先保住稿面内容，再排障。**

## 正文保存了吗？

正文会自动保存到当前浏览器。没有保存失败提示时，不需要手动保存；长时间写作后仍建议导出完整工作区 ZIP。

出现保存失败提示时：

1. 先点 **导出当前正文**，保存稿面上尚未落盘的内容。
2. 再点 **重试保存**。
3. 需要时查看恢复稿并比较时间、章节和内容。

此时不要先刷新、关页、清缓存或清站点数据。

## 为什么找不到原来的作品？

依次核对：

1. 是否仍在原来的浏览器和普通窗口中，而不是无痕窗口。
2. 当前网址是否与原来完全一致。协议、主机名和端口任一变化，都可能对应不同的浏览器存储。
3. 回到旧网址和原浏览器查看作品列表与可用恢复稿。
4. 如果有 ZIP 或 JSON 备份，先读取预览；确认覆盖范围后再恢复。

新网址没有显示作品不代表旧网址中的原稿已删除。不要为了“重新登录”先清站点数据。

## 怎样备份、换网址、换浏览器或换设备？

在原环境打开 **设置 → 备份与恢复**：

1. 优先 **导出完整工作区（ZIP）**。
2. 需要快速留底时，也可 **导出轻量备份（JSON）**。
3. 到新环境选择 **恢复备份**，检查新增、覆盖和跳过项目，再确认。

ZIP 覆盖范围更完整；JSON 不包含来源原件、媒体原件和已归档的记忆历史。两者都不包含模型密钥。作品不会自动跨环境同步。

## 选中文字后没有“批注 / 素材”浮条

先确认选的是中央可编辑正文，而不是章名、右侧回答或只读预览。关闭正在操作的查找、校对或其他浮层，回到正文重新拖选，松开鼠标后再点浮条。

仍不出现时，记录浏览器、当前打开的右栏工具，以及“在哪段文字上怎样选择”。如果准备刷新，先确认正文已保存。不要通过清除站点数据解决选区菜单问题。

## 推演已经有回应，为什么正文没变？

面板中的回应只是这条走法的记录。点“写成试稿”后，还会请求模型把走法整理成正文候选；检查候选并采用后，才写入稿件。若显示“查看试稿”或已有其他待处理试稿，先处理那份候选。

关闭面板、生成完成和采用不是同一操作。具体步骤见[创作与写作](./05-writing.md)。

## 推演重复了已经发生的事

先确认本次行动接在正确的步骤后；正文或设定已改动、面板提示过期时，用“重新确定起点”开始。检查人物、地点和本次条件是否仍准确。

模型仍可能重复描写或重演事件。不要采用错误试稿；反馈时附上最短必要片段：上一条回应、本次行动和重复部分。无需发送整本书。

## 识别到了人物，为什么还没入场？

识别只给出候选。打开“现场 → 调整当前场”，在候选旁点“选入在场人物”或“设为当前地点”，再点“保存当前场”。取消调整不会改变当前场。

识别依赖已关联世界书中的人物和地点；新名字需要先建立资料。同名、回忆、转述或“不在场”等说法要人工核对。没有新候选时也可以手动选择。

## 速记怎样改标题？

从“构思”打开速记，点击稿面顶部标题输入新名称，按 Enter 或点到标题外保存，Esc 取消。名称不能为空；失败时会提示“速记标题保存失败”。这不会重命名关联章节。

## 正文旧版本和“记忆与历史”有什么区别？

找章节旧稿，用“批注 → 版本”或章节菜单“历史版本”。找故事事实、提取候选和记忆修订，用“设置 → 记忆与历史”。其中一处没有记录，不代表另一处也为空。

## 助手说“没有依据”，是不是书里没有写？

不一定。回答使用本次检索到的片段，可能漏掉相关段落。“问全书”也不保证穷尽全书。把问题拆小，补上人物名、事件名或明确的章节信息，再核对回答引用；没有引用的建议不能当成原文事实。

## AI 按钮不可用或一直等待

写作和备份不依赖 AI，可以先继续正文。需要排查时：

1. 打开 **设置 → AI 配置**，选中准备使用的配置。
2. 点 **测试连通性**，记录完整错误信息。
3. 自定义配置请确认已经保存，API 地址、模型名和密钥符合该渠道当前说明。
4. 换过网址、浏览器或设备时，自定义配置需要重新添加。

不要把 API Key 发给维护者或贴进公开 Issue。

## 内置渠道提示未检测到可用模型

文本功能的唯一模型由站点 pi-agent 内核（Agent 任务面）持有，「未检测到可用模型」说明站点任务面没有运行或尚未选择模型，普通用户记录报错并联系部署者即可。

图片和视频内置渠道的密钥另由服务器持有。出现“服务器未配置 `MINIMAX_API_KEY`”说明当前部署没有完成媒体渠道配置，同样联系部署者处理。

部署者需要按服务端配置示例填写环境变量并重启服务。内置配置在界面可见，不等于所有站点都能直接调用。

## 自定义模型配置在别处不见了

自定义渠道和密钥保存在当前浏览器，不会进入作品备份，也不会自动跨网址或设备同步。请在新环境重新添加，并用渠道提供的安全方式保管密钥。

不要仅凭密钥前缀判断格式是否正确；以所选渠道的当前官方说明和连接测试为准。

## 页面显示异常、弹窗打不开或滚动失效

1. 如果稿面仍有未保存内容，先复制到本地文件或用 **导出当前正文** 保底。
2. 能打开设置时，先导出完整工作区 ZIP；必要时再导出低敏诊断。
3. 关闭浮层或切换一次页面后重试。
4. 内容已有可靠副本后，再刷新页面。
5. 仍无法恢复时联系部署者。清站点数据是最后手段，并且必须先确认备份可用。

## 地图生成慢或没有结果

大型地图和复杂参数可能需要较长时间。先等待当前任务结束，记录所用参数和错误；如果页面仍可操作，不要反复提交。准备刷新前先确认正文已保存并导出备份。

## 浏览器拒绝保存怎么办？

先复制仍在编辑器中的正文保底，并保留现有备份。不要清除网站数据。当前没有统一的空间清理工具；可在另一浏览器或设备中恢复备份后继续写作，确认作品完整前不要删除原环境的数据。

不要通过浏览器“清除网站数据”来整理空间，因为那会同时移除作品和其他本地内容。

## 怎样反馈问题？

按 [快速开始](./01-quickstart.md) 提供“想做什么、做了什么、预期与实际”。问题难以复现时，可以在 **设置 → 备份与恢复 → 导出诊断信息** 下载低敏 JSON；它不包含正文、标题、项目 ID、提示词、模型回复或 API Key，发送前仍可自行检查。

不要发送完整书稿、模型密钥或包含隐私的截图，除非你明确愿意并确认接收方。
