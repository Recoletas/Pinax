# 常见问题

## 作品不见了，先检查什么？

先回到原来的浏览器、用户配置和网址。HTTP / HTTPS、域名 / IP、不同端口属于不同存储空间；同一台服务器也不例外。不要先清缓存或重新导入覆盖。

如果换了设备或地址，在旧环境导出完整工作区 ZIP，再到新环境恢复。无痕窗口或清除站点数据后，未备份的数据可能无法找回。详见[备份步骤](./07-settings.md#备份与恢复)。

## Edge 为什么提示“不安全”？

2026-10-15 检查时，公网 `http://pinax.cc/` 仍使用 HTTP，HTTPS 尚未正常提供服务，浏览器因此提示连接不安全。这与是否能正常打开页面是两件事。

证书和 HTTPS 跳转需要部署者配置。切到 HTTPS 前，先在 HTTP 地址导出备份；浏览器不会自动把旧地址的书稿搬过去。部署状态见仓库的[故障排查](https://github.com/Recoletas/Pinax/blob/main/docs/operations/troubleshooting.md)。

## 保存失败怎么办？

保持页面打开，先复制还未保存的文字或导出可读取的稿件。按提示重试；若提示存储空间不足，先备份再整理媒体，别直接清空站点数据。

发生版本冲突时，保留当前输入，再载入最新内容核对。强行刷新或反复切换作品可能丢掉尚未保存的输入。

## 左侧目录和章节顺序有什么不同？

文件目录整理本书的章节、构思、设定和素材；章节顺序用于卷与章的叙事排列。移动文件夹不改变导出顺序。默认分类文件夹和右侧设定集合都引用原件，没有再复制一套内容。

## 点图标不知道是什么？

把鼠标停在图标上，或用 Tab 聚焦查看提示。写作和设定的右侧工具不同，切换工作台后工具会随之改变。手机在较窄空间使用抽屉或面板。

## 助手说写好了，正文却没变化？

检查权限和本轮工具：

1. **只读**模式只查阅和讨论。
2. **审阅修改**会生成建议，需要打开“查看修改建议”并采用。
3. **自动修改**也只覆盖已授权目标；目标变化、校验失败或保存失败时不能自动写入。
4. “读取章节”“查阅设定”是读取动作，不是修改回执。

没有修改建议时，明确要求修改哪一章哪一段。若工具显示失败，展开查看具体错误；不要把聊天文字当作已经保存的正文。

## 编辑问题或重新生成会新开对话吗？

不会。它们在原对话里生成这轮问答的新版本；**另开对话**才建立分支会话。顶部“对话”用于新建、切换和删除。

回看旧回答不会自动撤销已采用的修改。需要撤销时使用该次修改的撤销入口。详见[助手操作](./05-writing.md#助手)。

## 助手“未成功执行”或“回答未完成”怎么办？

先展开失败的工具看原因。可能是运行器未更新、目标修订变化、知识运行包不可用、模型超时或结果没有通过检查；仅凭这句提示不能确定是哪一种。

已保留的文字可以复制，未完成结果不能直接作为已校验修改采用。记录具体报错、操作步骤、是否连续发生，再反馈。不要把 API Key 或完整私密书稿贴入公开问题。

## 助手会自动读完所有作品吗？

不会。它会获得当前作品的有限上下文，按需查阅更多内容。可以用 `@` 或参考选择器指定章节、人物和资料。跨作品查阅须明确目标，读取能力不等于获得跨作品修改授权。

公网的本书资料查询和本机知识库检索范围不同。本机项目文档需要绑定目录，知识检索还需要知识运行包。零命中不能证明原文里没有这条信息。

## 推演可以什么都不填吗？

可以，默认从当前正文接着写。先看接续位置是否正确；新建空章没有上下文时，补充人物、处境或方向会更可靠。

**写下一段**在正文位置展示待采用草稿；**推演情节**在右侧尝试发展，选好后再写成正文。Enter 发送，Ctrl+Enter（Mac 为 ⌘+Enter）换行。移动光标或关闭右栏不会自动采用草稿。

原文或参考变化时，旧结果会保留供查看，但可能不能直接采用。先保存有用内容，再重新选定起点。不要反复生成来解决一次保存失败。

## 当前场为什么没自动加入提到的人物？

人物被提到不等于在场。识别只提供建议，确认后才保存当前场；回忆、引用或否定句尤其需要核对。新人物也不会只凭一个名字自动成为正式设定。

## 设定和属性为什么没一起改？

自由正文与结构字段各有用途。属性生成的描述与手改正文不同时，需要选择保留正文或明确覆盖，不会静默替换。管理、属性或表格还有未保存内容时，会阻止切换并保留输入。

## PDF 导入失败或没有内容？

确认文件未超过限制：PDF 100 MB，其他文件 50 MB。扫描 PDF 没有文字层时先做 OCR；受保护、损坏或结构特殊的文件也可能解析失败。先检查预览再加入本书，必要时改用 TXT / Markdown。

项目文档当前是只读阅读器；添加资料不会把任意文件变成可写文档。

## 生成图片或视频失败，但文本模型能用？

文本、图片和视频是独立配置。文本连通不代表图片或视频渠道可用。

视频查询中断时先用“继续查询”；原件保存失败时重试保存，不要重复生成。只有“原件已保存”的结果可脱离临时链接使用；轻量 JSON 不含这些原件。漫画还需要核对当前格、阶段确认和文字溢出。

## 批注浮条不出现？

在中央正文重新选中文字，确认不是选中了助手回答或预览。若正在操作查找或校对，先关闭该面板再试。仍异常时，记录浏览器、缩放、打开的工具和复现步骤。

## 应该备份哪一种？

要迁移作品和资料用完整工作区 ZIP；只要可读稿件用正文导出。轻量 JSON 不包含来源和媒体原件。原始 PDF / Word、自定义模型密钥也请分别保管。

## 怎样反馈问题？

附上页面入口、具体操作、预期结果、实际报错、浏览器及主题。工具失败请展开错误截图；保存问题先保留数据。可到 [GitHub Issues](https://github.com/Recoletas/Pinax/issues) 反馈。
