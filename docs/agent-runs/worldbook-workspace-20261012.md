## 实施

- `WorldbookContentWorkspace` 统一内容目录和条目编辑。世界规则、人物、势力、地点、历史是内容分类，详情／表格／关系图是同一批内容的查看方式。没有方法论一级标签，也没有第二套全局导航。
- 详情直接编辑名称和正文；表格默认隐藏模板、档位、缺项等管理列，字段列仍可选择。未选模板的条目按已有正文标签编辑，不自动绑定模板。
- 关系图使用现有世界书关系，少量节点常显名称。详情可选择关联对象，图谱 Shift 拖拽同样产生待确认关联；确认后通过既有双层关系函数和 `worldStore` 写入。
- 伏笔台账仍是结算链原有条目中的表格，不另建数据库。创作基调复用原 `StructuredSettingsWorkspace` 连续编辑、AI 候选与来源能力。
- 原 `/settings/structured` 和工作区 `settings-editor` 使用同一内容组件。正文角色／设定的展开操作携带当前条目进入主区；窄旁区采用横向内容目录和条目编辑，手机使用同一内容对象。
- 标签保存的只是条目、分类和查看方式。移动保留组件；刷新恢复位置，世界书内容仍由原 repository / `worldStore` 持有。

## 保存与失效

- 正文编辑使用 `expectedFingerprint`；指纹补充 profile、关系、状态和档位，避免只改字段时并发校验漏检。
- 切条目、分类、查看方式、关闭工作区及旧路由离开复用 `flushAll`。输入法组合输入和待确认关联会阻止离开。
- 详情未保存输入使用现有 `entryPanelDraft` 的独立 `workspace` 面保存；保存失败或版本冲突保留输入，提供重试与作者确认的载入最新。保存过程中继续输入时保留新草案及新的版本基线。
