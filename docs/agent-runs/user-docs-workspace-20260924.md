## 本轮调整

- 按“正文先开始、AI 按需介入、世界书逐步建立、视听与跑团作为扩展”整理指南首页、快速开始、创作工作台和设定页。把工具说成作者实际要完成的任务，不要求先建完整世界或配置 AI。
- 补充素材从正文选区建立、人物/设定与记忆账本的区别、工作台批注/助手/推演/现场/历史流程，以及视频编导和漫画的输入、候选、检查与限制。
- 新增素材卡、画布节点、漫画生成前输入态截图；明确这些图显示真实操作结果，不是 AI 输出。现有跑团图是本地固定演示推进，不是模型主持结果；助手与推演图展示待发送输入，不冒充回答。
- 首页、资料来源导入、素材、画布、漫画、跑团等图来自本地运行应用；工作台主稿图使用用户提供的实际截图。正文相关补充截图现统一使用用户图中的同一段落内容和单段换行；之前的双换行会额外生成空段落，导致段间留白不一致，已重拍 03–06、10、12–13。右侧不同工具面板实际宽度不同，因此各页每行字数会随可用正文宽度变化，不用裁图或缩放把它伪装成固定宽度。

## 截图尺寸与页面缩放

Chrome 截图文件为 **2559×1396 物理像素**；相应 CSS 视口是 **2047×1117**，设备像素比 **1.25**。截图环境把 Pinax 的 `app_ui_zoom` 设为 **1（100%）**。先前把物理像素误当 CSS 视口，且沿用应用 85% 默认缩放，造成页面密度和用户截图不同；本轮已按 CSS 视口、DPR 与缩放重新采集相关页面。工作台主稿图直接使用用户提供的 2559×1396 图片。

截图位于 `public/docs/screenshots/user-guide-20260924/`，由生产构建复制至 `dist/docs/screenshots/`。已核对新增截图均为 2559×1396；没有裁切来伪装浏览器比例。DocsPage 将手册中的相对截图地址映射到 `/docs/screenshots/`。
