## 约束与实施

- 两侧服务正文阅读，作品导航、稿件目录和工具入口各有明确层级。
- 作品标题与四项导航固定；章节、构思、语言和关联资料独立滚动。
- 章节提前，章序/标题分层；新建章归目录标题，新建书归作品标题。
- 工具按写作、参考、辅助排列，保留可见名称、选中与键盘焦点。
- 助手侧栏使用紧凑操作行、回答行距与固定底部输入；全屏阅读比例保留。
- 手机目录有直接关闭入口，仍调用既有关闭/焦点恢复 owner。
- 采纳动作使用明确按钮；未完成/保存失败/作品归属规则沿用现有实现。
