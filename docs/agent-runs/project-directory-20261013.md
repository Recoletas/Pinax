## 实施

- 正文左栏提供文件目录与章节顺序。文件目录读取章节、构思、设定条目、来源和素材；图标、短类型词与只读提示共同辨识。旧章节顺序、写作工具轨和双栏继续保留。
- 支持同一文件夹内混排、新建与重命名文件夹、移动、拖放和上移／下移、按名称／类型筛选、在文件夹中显示。新建章节／构思调用原 owner 后归档到选中位置。移动不更改章节导出顺序；移除文件夹只将内容移到上一级。
- 目录只保存 ID、父子关系、顺序与关联。正式内容不复制，新增动态存储键纳入既有备份；损坏记录和写入失败保留原数据。修订比较避免覆盖已经观察到的其他窗口更新，不宣称跨进程原子事务。
- 构思接入已有资源合同；主区编辑、旁区只读，章节与构思不新增顶部标签行。正文进入其他主区视图时，原左栏移动到宿主；手机可用“目录”按钮展开。
- 单条设定从目录打开默认聚焦正文，“浏览设定”恢复集合。可展开属性与模板，空字段按需添加。只存字段或覆盖正文仍须显式选择，沿用条目指纹和草案恢复；未保存属性会阻止切换，失败不清空输入。
- 在目录选中项的更多操作内关联本书不同类型的内容，双方均能查看关联并打开原件。移除关联不删除内容；原件缺失显示失效信息。
