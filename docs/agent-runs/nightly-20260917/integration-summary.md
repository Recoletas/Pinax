## 审查发现与修复

1. **A 的生产接线原来只是补丁**：实际接入 authoring reader host 的原 memory 链；使用请求冻结的 bookId，按请求关闭数据库连接。审计不携带被排除正文，失败保留旧候选通道。只抑制实际送入上下文的迁入版本，避免整张迁移表抑制有效旧记忆。
2. **事实内容被强制转小写**：改为保留 object 的大小写及内部空白；标识键仍按既有合同规范化。防止名称/单位等内容改变；已被旧版本转小写的历史不会自动猜回原文。
3. **完整备份未包含新账本**：接入 v3 ZIP 可选域；账本导出使用只读事务冻结，缺库失败不产出伪完整包。检查 schema/count/scope/证据引用/更正链/序号；旧包缺域明示且不清库。
4. **备份失败路径假回滚与连接泄漏**：ledger 导入失败后真正恢复媒体及来源；补偿独立尝试，异常不跳过下一域；补齐 localStorage 异常时 ledger 回滚和连接 finally。
5. **记忆界面换归属竞态**：立即清除旧域展示，读取有 generation fence，迟到查询不回填到新书。
6. **C 在会话 durable 保存前就异步归档**：改为 coordinator 保存成功后才 drain。最终保存失败恢复 pending/骰点、receipt/outbox、回合游标与检定显示；后台派生观察器失败不撤销已保存正文。
7. **重叙述改写已归档回执**：保留原规则结算的 turn/branch/time/evidence；新叙述引用原 actionId，不虚构第二次检定或改写原事实。
8. **分支快照不含跑团运行态**：新快照纳入场景、资源、主持、旅伴、角色；pending/receipt/outbox 仍为会话审计数据，不随每个回合复制或清空。旧快照缺这些字段，不能追溯重建。
9. **角色知识混用作者事实**：移除未验证的 queryFacts 接线；当前旅伴只用场景公开投影，明确 `character-knowledge-reader` 未就绪。它是确定性建议，不冒充自主模型 KP。
10. **B 丢失响应被当作已知失败**：网络异常/超时/不确定服务端错误保留请求身份，重复点击被持久守卫拦截；明确的 HTTP 4xx 拒绝可释放。仅显式处理未知请求后允许再生成，不冒称跨设备 exactly-once。
11. **复用许可未完整随包分发**：核对固定 StoryForge LICENSE；骰子移植与漫画设计借鉴分开登记，MIT 原文随 public 构建发布。Utopia 仍是设计参考而非复制 Rust/SQL。
