## 实际交付

- 人物 IF 复用同一冻结 manifest 和内存模型配置（凭据不写文档/实验元数据），两支分别规划行动。只提交作者选中的那一支；相同行动不视为失败，预测与作者假设不改正式世界书。
- 各支草稿保存自己的文本、原稿、上一稿、候选、目标与 receipt。切换零模型调用；采用受既有 revision/事务门禁控制。采用一支后另一支保留但 stale，不能直接沿旧锚点续写。
- 追加要求失败保留；构思保存失败可重试、双击不重复、迟到返回不清新稿，保存内容含条件/来源版本。上一稿可展开阅读。
- 提炼入口不再打开原稿冒充预览。现提供明确标注的本地规则初筛、选词补候选、类型/标题修订、关联已有对象和保存构思；不自动写正式设定。原文版本变化或关联对象失效时拒绝保存。
- K 显式焦点资料接缝、IF 合同与 pinned 版本校验纳入主线。pinned 无对应版本时明确失败，不伪造历史存储。
- main 人物/现场入口接到同一流程；重复 IF 面板/合同原型不进入最终运行时，原稿留备份，不丢失其入口用途。
