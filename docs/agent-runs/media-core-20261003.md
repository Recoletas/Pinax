## 方向与分工

漫画和视频是制作工作区：中央保留实际画面，沿边放当前步骤的操作；宽屏便于预览与编辑，手机按任务切换。沿用 Google / iOS 方向中的中性面层、系统字体、统一控件和轻量状态，不引入新的视觉主题。

| Owner | 写集 | 当前任务 |
|---|---|---|
| root | ProseEssay、导演交接、时间轴、文档 | 画布到视频的连续流程、组合检查和截图 |
| video_workspace | StoryboardVideoPanel、VideoModelPicker、videoJobService、videoProviderConfigStore | 提交、恢复、取消、预览、保存链接与响应式 |
| comic_workspace | ComicStudio、Comic 组件、comics composables、comic 服务 | 新建与换页、当前格、分阶段制作和导出 |
| media_backend | server/media、server/routes/media | 查询重试、终态转换、取消与并发释放 |

保留已有工作内容。调查开始后的文件快照在 `/tmp/pinax-core-media-20261003/before`，不是干净分支基线。各 worker 输出简报，root 再核对实际差异和组合结果。

## 核查范围

- 漫画：新建页 → 分格 → 上传或生成 → 对白 → 确认 → 导出；切页、切书、刷新及失败状态。
- 视频：时间轴 → 分镜版本 → 模型与镜头 → 提交 → 查询/取消/恢复 → 预览 → 保存链接。
- 实际界面的桌面、手机、亮暗状态；隔离浏览器中的合成作品数据。
- 工程门禁与确定性任务故障检查；不发起收费模型任务，不以模拟结果宣称真实生成质量。

## 已实施

### 视频与画布

- 视频面板重排为镜头、画面描述、模型参数和结果；手机使用底部面板，模型选择浮层置于其上，嵌套 Escape 只关闭当前层。
- 同步提交锁防双击；关闭、切书与迟到结果按原任务处理；在当前标签页保存无密钥的恢复记录，重新打开/刷新查询同一任务。
- 内嵌播放器，链接保存失败仅重试保存；按钮明确“打开原视频”“停止等待”，不把外链当成文件归档。
- 导演交接支持失效/卸载围栏，固定画布分镜身份；相同内容刷新复用版本，分镜写入失败不打开生成面板。镜头建议必须收到落盘回执才算采用。
- 多作品素材混在时间轴时阻止视频归属被随意取成第一本书；共享画布本身仍沿用既有全局存储，不在这一轮迁移历史卡片。
- 时间轴可键盘选中，取消五镜头列表原先的固定高度限制；收紧操作留白，场景板移除桌面重复手机导航。画布保存失败展示状态，文本框保留原生撤销。

### 漫画与插画

- 当前格操作分为画面、文字、分阶段精修；页面参数、质检和导出放在“页面与导出”。新建第二页真正创建并保存，折叠检查器保留编辑器实例。
- 增加无模型直接上传图片，支持 PNG/JPEG/WebP，20 MB 上限；复用候选、作品/格归属和只重试保存的规则。
- 消除换页保存 hook 的递归；保存失败阻止离开当前页。作者字段保存合并后台最新候选与 pending，避免旧快照覆盖新图；画面、节拍、来源变化使阶段结果失效。
- 阶段“明确再生成”携带明确的旧请求 ID，解决本地清记录后仍被旧 props 拦住的问题。
- 默认排字按真实格尺寸和文本给初始气泡留足空间；保留手工框尺寸与长文本溢出拦截。
- 插画切换来源后，旧任务仍在途时提供“停止上次生成”；停止结果不会进入新来源。

### 视频后端

- 每个任务只提交一次上游；查询重试沿用同一渠道任务，有限次数，不再因查询失败重复生成/计费。
- 首次查询即成功可以正确结束；取消唤醒等待、释放并发槽，迟到请求无法覆盖终态。
- 参数在建任务前验证；通用模板原样保留 `$&` 与占位符字面文本；错误与日志去掉凭据，连接探测不把 HTML 200 当成模型鉴权成功。
- 核对现有 MiniMax Hailuo V1 的[提交](https://platform.minimax.cn/docs/api-reference/video-generation-t2v)、[查询](https://platform.minimax.io/docs/api-reference/video-generation-query)和[下载](https://platform.minimax.io/docs/api-reference/video-generation-download)接口；没有把 H3 V2 的取消合同套进现有渠道。
