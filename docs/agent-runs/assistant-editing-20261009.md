## 已接通的行为

- 助手统一接收讨论、查阅和写作要求。输入区改为只读／审阅修改／自动修改及范围设置，章节、角色设定、大纲分别授权；权限菜单按触发按钮定位，加号仍向下展开。
- 写作交付通过 `submit_edit_proposals`；`complete_assistant_task` 明确意图和结果，编辑不能仅用聊天正文完成。缺交付最多补一次，依然失败则保留文本并报错。
- 正文修改在段落处预览；逐处接受、拒绝，相关组原子处理；设定和大纲仍在现有面板审阅。支持替换、末尾追加、原文锚点后插入、删除和新建。
- 应用前检查目标归属、当前授权、正文位置和跨窗口处理状态。采用走既有多键事务日志，保存失败回滚；保存修改前版本，支持事务撤销和正文 Ctrl+Z 边界。
- 自动修改只应用有效授权下的提议；撤销在途授权会停止上游请求。新会话、切书和页面重载不继承自动授权。手机可在助手回答处直接撤销。
- 当前场摘要、编辑、识别候选、来源详情和场景因果进入推演。工具轨保留助手／推演／批注，大纲／角色／设定，记忆／双栏三组。
- 现场识别仍使用现有同步服务，不增加模型调用。使用时按正文与目标版本检查，移动光标不重复扫描同一段；候选仍需确认，未采用提议不进入识别。

## 使用边界

1. 公网仍使用浏览器 capability 隔离，不是账户权限系统；工具不获得服务器文件或命令权限。
2. 提议上限沿用 8 处／24 KB；正文读取快照仍有限长，未覆盖的位置不能伪称已通读或任意修改。
3. 同段发生冲突时保守阻断，不自动合并作者与模型改稿；跨浏览器设备不提供共享锁。支持 Web Locks 的浏览器使用同源锁，其余浏览器仅进程内串行，并保留存储基线保护。
4. 现场是共享状态。已采用文本在下次使用时参与识别；自动修改授权不会自动确认人物入场。
5. 深色、浅色与手机截图需实际查看；临时截图与测试运行目录在验收后清理，不长期留在仓库。
