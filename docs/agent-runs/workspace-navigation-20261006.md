## 设计合同

首页是默认入口和继续工作入口；作品内是持续编辑工作区。桌面/平板/手机分别按实际空间重排，沿用现有亮暗 token 和用户缩放。第一眼应读懂当前作品、当前内容、主要动作；空库、空书、多作品与长目录都使用真实状态。

1. 首页保留；继续上次能识别作品与对象，最近工作按使用时间排序，与修改时间分开。
2. 顶部抽屉、完整助手、资料和漫画共用作品导航；正文左栏恢复改造前的搜索、新建、语言、构思、卷/章和世界书关联，当前场固定底部。
3. 正文、助手、设定、资料等功能由顶部“导航”展开，不在稿面左栏常驻；更多工具打开灵感、地图、漫画、视频，不新建中转页。
4. 保留页签与各页面保存/生成 owner；切书清掉旧对象定位，失效目标给明确说明。
5. 最近记录只存有限导航元数据，关闭页签后保留，不保存正文或候选。
6. 漫画页/格和正文章节恢复到合法对象；临时光标账本不冒充跨会话恢复。
7. 用共同排版和连续面层组织内容；不添加装饰背景、大卡片或假数据。实际查看 1440/900/390、亮暗与长标题。

参考证据沿用上一轮已查看的 Obsidian / VS Code 官方图与文档，详见上位方案；这是 Pinax 的具文字导航适配，并不复制代码编辑器的全部分屏与文件系统。

### 修改

- 作品选择器与新建动作同一行，移除左栏重复首页入口（首页仍是常驻顶部页签）。正文、助手、设定、资料单列；灵感、地图、漫画、视频改为“更多工具”弹出列表。选中功能以文字字重和图标颜色表示，取消并排小按钮、媒体子列表及圆角选中块。
