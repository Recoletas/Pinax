## 已实施

- 文本块：复用 canonical writingUnit，完整页边边界、当前/全部/隐藏偏好、专注隐藏；原右键菜单增加下一块合并、审阅与生图。页边按钮保持绝对定位且阻止点击冒泡，不写入正文。当前审稿块有独立虚线标记。
- 助手：现有右栏增加目标审稿；三种方法、精确选区/当前块/文稿范围、规范化 writingSkill 请求与服务端 applied ack 对账。按真实成功批次计算不重复字数，每次最多 8 批，继续只发剩余批次。保留已忽略意见状态。主栏与副栏意见均进入既有 rewrite，候选可微调、采用、撤销；副栏切换助手时隐藏保活，保持同一事务与保存 owner。对话文字锁以源位置复验，不能用另一处相同句子蒙混通过。
- 生图：沿用现有宽抽屉和媒体持久化。每张独立生成/保存，后续失败不回滚成功图片；未存图片可下载或只重试保存。提供逐张状态、继续未生成项、对照、参数复用和已存图下载。刷新后只恢复最小任务元信息与已落盘成果，不保存像素、密钥或自动重发付费请求。上传冻结所属作品，核验类型/签名/实际解码及体积。整理画面描述是显式调用文本模型，返回可编辑草稿，采用前不覆盖输入，可恢复上一描述。
- 恢复与备份：审稿保存目标、完成批次与结果引用；生图保存 job/item 状态和媒体 ID。运行中刷新统一转为“已中断”，继续前重验正文 revision。新增运行记录与写作显示偏好均纳入现有备份和 storage policy。
- 参考能力：按 adapter 和已覆盖模型收紧；未知 OpenAI 图片模型不会被偷偷换成另一模型。自定义 endpoint 保留，参考图过量明确拒绝；无图像参考能力时必须明确选择仅文字生成。参考强度只在实际消费该参数的适配器出现。兼容接口行为仍需对应渠道验证，不能从字段存在推断人物一致性。
