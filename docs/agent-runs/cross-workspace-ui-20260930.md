# 作品工作区联动与 UI 打磨

## 本轮输入与约束

作者反馈：助手与其他界面缺少联动感，其他页面也要打磨。助手的大体方向此前仅获初步认可。本轮沿用作者 Gemini 实物截图中的安静工具感，将它接回 Pinax 的创作工作区。

1. 正文、助手、设定、资料采用相同名称、图标与导航反馈；在已有工具行和侧栏中连接，不再加一条全局工具栏。
2. 同书跳转明确携带作品归属；正文与助手共用 Authoring 标签和作品会话，返回动作与显示文字一致。
3. 工作面、目录、输入与弹层共用主题 token；暗色不再在黑色助手和灰色编辑器之间明显跳变，亮色保留同样层级。
4. 导航和工具用无衬线字体、统一间距与轻选中反馈；正文、作品封面、画布坐标、关系线和数据编辑仍由原 owner 负责。
5. 首页、素材、画布/视频、漫画和体验的公共工具与空态遵循相同层级；真实功能入口保留，旧装饰微标改成可读的常规控件。
6. 手机重新编排工具行，点击区域至少 44 CSS px；长作品名和较多导航项不造成整页横向溢出。
7. 用隔离的合成作品看完整路径和真实截图；本轮不新增/运行自动测试、模型、提交、推送或部署。

## 初始证据

九页暗色 1440×900 图位于 `/tmp/pinax-cross-ui-audit-20260930/`。root 已查看首页、正文、设定、资料、素材、画布、体验、漫画；助手实物方向来自上一片。主要割裂：助手与其他页面层明度不同，导航尺度不同，设定/资料缺少本书助手入口；素材与画布残留装饰顾问章与多套控件。

静态审阅发现结构化设定页仍读取全局 activeWorldbook，而项目加载器已使用按书快照；返回正文可能激活包含 view=assistant 的标签。先修这两处，再扩展作品入口。

## 本轮结果

已实施正文/助手共用四入口，设定/资料可明确返回正文或助手；同一作品只有一个 Authoring 标签，章名和展示意图随标签恢复。首页工具选书与继续书稿共用最近有效项目标签，保留手动选择。

共享面层、顶部标签、工具和导航已统一。素材/画布/漫画/体验收拾了公共操作、空态与顾问入口；不改画布坐标。资料列表与原文预览使用同书 scope，切书清掉旧预览；设定/条目/地图读取当前作品快照，正式保存后按 ID 更新。地图当前片只处理归属和保存保护。

初轮隔离截图 31 张（1440 明暗、390、320 英文/85%）无 pageerror 与整页横向溢出，位于 `/tmp/pinax-cross-ui-final-20260930/`；root 已实际查看正文、首页、设定、资料手机、素材、画布、漫画及窄屏英文设定。两部虚构作品的资料→助手→设定→切书→助手路径已观察：ID、章节和库匹配，换书不残留预览。工程检查已执行：Vite build、VitePress build、lint:delta（0 error/2 存量 warning）、结构、体积 exit 0；主 Authoring chunk 1,404,157 bytes / 1,450,000。结构首轮发现 Notes 新增 import 超 18 上限，已迁入现有 catalog composable，复跑通过。根截图轮后又修了正文滚动面层和设定来源的竖排装饰，首页 worker 已复拍 320px 英文菜单；最终细节仍待作者预览确认。
