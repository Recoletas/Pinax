# 工作区文案减量 · 2026-10-15

## 范围与依据

用户指出当前场标题／待设置重复、左栏多出“文件”、首页图标旁仍有文字，要求检查其他页面。这轮调整导航、辅助文案与相应间距，不改变正文宽度、资源归属、保存、模型调用或权限。

参考的是官方规范与官方设计说明，不声称体验过这些产品的全部最新客户端：

- [Microsoft：Writing style](https://learn.microsoft.com/en-us/windows/apps/design/style/writing-style)：直接表达操作，删去铺垫；必要信息不能因追求简短而消失。错误需要说明情况及可行的下一步。
- [VS Code：Views](https://code.visualstudio.com/api/ux-guidelines/views)：限制视图数量、标题长度、欢迎文案和操作数量；仅在需要时使用欢迎视图。它没有要求删除所有视图标题。
- [Linear：2026 界面调整说明](https://linear.app/now/behind-the-latest-design-refresh)：统一导航与视图控制，减少多余图标、分隔线和视觉竞争；内容应占主要注意力。这是官方文章的设计解释，不是对 Pinax 布局的直接规定。

对 Pinax 的应用判断：一个位置只表达一次上下文。固定标题、分类选择器、实际值、空状态不必各重复一遍同一意思；说明放在真正需要理解后果的地方。不能用隐藏功能、删错误或让用户猜图标来换取“干净”。

## 明确保留

只读和未归属旧素材、世界书绑定失效、保存失败、待确认修改、自动修改权限及范围、视频原件与远端链接区别、检索覆盖范围、属性投影冲突、跑团检定后果。它们帮助用户作决定，不能和装饰性小字一起删去。

首页最近使用的时间、目录非空计数、设定列表摘要也保留：这些是实际内容和寻找线索。没有把所有界面按钮都改成图标。
