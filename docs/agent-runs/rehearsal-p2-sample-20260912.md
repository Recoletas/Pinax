莉娜的身影消失在楼梯尽头，脚步声渐渐远去。

艾德加站在原地，眉头紧锁，目光久久停留在她离开的方向。他轻轻咳嗽了一声，声音在空旷的税务所里显得格外清晰，似乎想借此引起某种注意。

然而，他最终只是低声自语：“总册的事还没完……” 他的目光转向第三排书架，那里一盏油灯静静燃烧，灯焰微微向左偏斜，仿佛被某种无形的力量牵引着。

艾德加的手不自觉地摸了摸胸前的黄铜吊坠，那是他在税务所多年工作的习惯性动作，似乎能从中获得某种安慰或灵感。

他走向那张堆满文件的木桌，目光被一把黄铜钥匙和一张字条吸引。艾德加的眉头皱得更深了，他犹豫片刻，伸手拿起字条，快速扫了一眼。

“她到底发现了什么……”

他的声音低沉而谨慎，仿佛不愿让任何潜在的听众听到。艾德加将字条小心地折好，放进口袋，然后拿起那把黄铜钥匙，仔细端详。

他的手指轻轻摩挲着钥匙的齿纹，似乎在判断它的用途。

片刻之后，艾德加将钥匙也放进口袋，转身快步走向第三排书架。他的脚步略显急促，显然心中已经有了某种计划或推测。

书架前的灯焰依旧摇曳不定，艾德加站在灯旁，目光在书架上快速扫过。他的手再次摸向胸前的吊坠，仿佛在回忆或确认某些重要信息。

“总册……莉娜的字条……钥匙……这些线索之间到底有什么联系？”

他的目光停留在书架的某个位置，那里似乎并没有什么特别之处，但艾德加的眼神却变得锐利起来。他伸出手，轻轻敲了敲书架的木板，发出沉闷的声响。

艾德加深吸一口气，似乎下定了某种决心。他从口袋里掏出钥匙，试探性地插进书架底部的一个隐蔽锁孔中。

钥匙顺利地转动了一下，接着传来轻微的咔哒声。书架底部的一块木板缓缓打开，露出一个隐藏的暗格。

艾德加的眼中闪过一丝惊讶，但很快被冷静取代。

他蹲下身，仔细查看暗格中的物品。那里静静地躺着一本泛黄的册子，封面上写着“嘉禾十七年船税总册”。

艾德加的嘴角微微上扬，似乎找到了他一直在寻找的东西。

“莉娜，你果然发现了关键。”

艾德加将总册取出，小心地放进随身携带的皮包中。他站起身，目光再次扫过书架，似乎在确认没有遗漏任何线索。

最后，他转身离开书架，步伐坚定地走向税务所的出口。艾德加知道，接下来的每一步都至关重要，而他，已经准备好了。
