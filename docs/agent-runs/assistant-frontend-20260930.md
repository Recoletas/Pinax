# 助手前端首版

2026-09-30 · 本地 `main@ebaebc5` 上的未提交改动。保留原有设定页切书和合作文档 WIP。

## 已实施

- 顶部「助手」打开完整页，侧栏「完整助手」展开同一对话；返回时编辑器仍挂载，恢复原章节滚动位置。
- 空白作品可以从助手开始；新建作品可选「直接写作 / 和助手构思」。构思可以暂不填书名，构思入口只填输入草稿，不自动调用模型。
- 来源先在助手里预览片段，再打开原文；手机用独立预览面板并可返回对话。沿用现有来源授权、版本对账、审稿、批注和采用链。
- 每书分别保存对话与草稿，草稿防抖并在离页时冲刷；备份登记对应动态存储前缀。刷新只恢复内容和中断提示，不重发请求。
- 每书独立请求状态，准备输入在第一次 await 前固定；迟到结果只更新启动时的书。停止/失败只恢复未经编辑的原问题，读取失败锁自动覆盖，重试不重复带入末尾问题。
- 新回答有未读提示；最近对话有限带入下一次问题，旧回答不作为作品事实或引用来源。
- 查询目录按需加载。界面保留亮暗主题、手机布局和英文文案。
