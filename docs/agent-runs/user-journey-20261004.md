## 巡检遗留问题与后续修复

作者要求继续解决巡检发现的问题后，逐项复现、修复，并重新调用实际渠道。以下结果来自后续修复，不把第一次失败改写成成功。

| 问题 | 原因与改动 | 复验结果 |
|---|---|---|
| 地点提取 502 | 渠道忽略结构化模式/强制工具，实际返回完整 JSON 文本；原链路没有接受。现在单独记录 `text-json` 模式，仅允许完整 JSON 或单个完整围栏，仍校验字段、枚举、数组与额外属性 | 实际 14.25 秒、HTTP 200、一次请求取得雾港/北岬灯塔/旧仓库三条草稿。采用前正式地点为零；确认三条后刷新保留 |
| 小港变成国家地图 | 生成依据混入全局地理状态，零国家/零城市参数又被默认值覆盖。改为当前世界书独立依据，提供局部/世界范围，局部不自动生成政体和命名聚落 | 实际局部海岸地图为 0 国家、0 城市、0 自动标记；原地点名保留，未擅自绑定。手动定位、确认、刷新、回设定、解除、刷新、重绑均实过 |
| 地点解除后复活 | store 修改地点时重新读取旧 payload，覆盖新绑定/解除值；修为使用当前合并值并保留显式 null | 解除后顶层和 metadata 都为空，刷新仍解除；另补米级比例尺和手机资料层遮挡 |
| 漫画分页网络失败 | 非流式长响应约 29 秒断连，换模型同样失败。改走既有流式通道，一次请求，120 秒预算、3600 token，可取消 | 原内置 Text-01 40.985 秒返回两个方案：2 页 4 格/2 页 5 格。实际切方案、改标题和规则、建两页、确认、刷新、切第二页制作全部完成；此次没有把空白格算成成图 |
| 推演越过指定结尾，critic 误判 | 原检查依赖模型场景计划且发生在发布后。现在冻结作者原始要求，先检查再提交；终点必须给出唯一逐字锚点，程序复核锚点后是否仍有正文，最多修订一次 | 英文到站广播、“我明白了”收束、螺钉交接后确认三个真实样本均发现越界、修订后通过；明确允许的新医生、交接动作保留 |
| 跑团代替玩家行动/推断 | 只提供公开场景、本次行动、已裁定结果和可揭示线索；发布前复核人物来源、玩家决策与无依据排他推断。失败不写入可见叙事 | 井盖失败检定保留失败结果、铁锈和回声，通过。航海记录稿仍会写无依据推断，真实修订后也未合格，最终被阻断而非发布；这一例不能算生成成功 |
| 未来承诺变成已发生事实 | 原提取限定可能只在元数据里，账本正文丢失。现在从来源恢复完整句，限定缺失时保留为“原文记载”，不自动推断肯定/否定；缓存策略一并失效 | 3 次真实提取、8 条有效候选覆盖承诺/否定、转述/条件、承诺后实际交付；接受“答应明早交信”后，账本读取仍保留“答应”，没有变成已交信。补修同毫秒新 revision 排队 |
| 视频只有临时链接 | 新增受控原件下载：只读已完成任务，校验公网 HTTPS、固定 DNS、逐跳检查，不开放任意网址代理；前端自动保存到既有媒体库，失败可重试 | 本轮唯一实际视频生成完成：497,367 字节 MP4、1366×768、5.875 秒。关闭重开不重复提交；本地播放、刷新、下载成功 |
| 视频备份缺原件 | 原件进入 IndexedDB 后复用完整工作区 ZIP，播放优先本地文件 | 实际 UI 导出 504,008 字节 ZIP，在独立空浏览器通过设置导入；封锁外部网址及服务端原件下载后仍从 blob 播放，画面/时长正确，无 pageerror |

### 文本质量的实际边界

本次写作与跑团共 31 次实际供应商步骤，包含生成、检查、修订、复核及保存真稿的审核重放；重放不算新生成。模型审核确实多次把坏稿标为 pass，因此不能仅依赖模型自评。现在明确结束锚点及跑团断言有程序核查；修订仍不合格就保留原文并提示重试，不悄悄删句或代替作者接受。

这些规则不能证明覆盖所有隐含因果、未署名人物或所有合法释义。普通无明确约束的“接着写”不额外执行这一整轮检查；严格检查与修订仍计入原任务步骤、时间和 token 预算。三份合格写作稿和失败检定稿经实际叙事组件呈现，协议标记没有泄漏。

视频原件保存在当前浏览器，单文件上限 64 MiB；旧任务失效、链接过期且原件从未保存时仍可能无法找回。完整 ZIP 只包含保存成功的原件，轻量 JSON 不包含。清除浏览器数据前应下载文件或导出完整备份。
