# 界面续修 · 2026-10-03

## 本轮改动

按既有 Google / iOS 研究和 Gemini 参考，接入正式 Vue 界面。本轮集中处理共同外壳、作品导航、助手和设定标题带；原有 UI WIP 继续保留。

- 页签、工具栏和侧栏共用一个外围底色。阅读区保持实色，亮暗分别定义输入面与菜单面；控件、工作面、菜单使用各自的圆角。
- 正文/助手/设定/资料的主入口采用浅蓝选中，章节和会话采用中性选中。当前入口在悬停时仍保持选中表达；键盘焦点和按下反馈独立。
- 桌面活动项目页签加宽到 204px，继续支持横向滚动、完整标题提示和独立关闭按钮。
- 助手输入改成全宽文字区和下方动作区，文稿回程置于输入面内。回答、输入共用 760px 阅读列；空态局部使用浅色和轻阴影，引用改用细边。
- 设定作品选择器减轻常态底色；局部分区用中性下划线，手机的正文/助手回程显示文字。直接进入窄屏条目页时，当前页签自动显露，只调整导航自身横向位置。

首轮实际截图发现 320px 英文助手中，文稿回程被挤到零宽。已把手机上下文排成独立一行，保留完整章名省略规则与 44px 点击高度，工具、用途和发送排在下一行。

## 实施边界

助手两个 Vue 的业务脚本与开工副本字节相同；设定的作品切换、路由参数、来源提示和回程逻辑保留；仅增加窄屏挂载/切分区时让当前分区在自身横向导航内显露，不移动正文或抢焦点。原文排版、模型、存储和正式采用流程沿用现有 owner。只读审阅及助手、设定两个切片按分离写集完成，主 agent 负责组合构建和实际看图。

新增 `--surface-workbench-overlay` 专供菜单内容；既有 `--surface-overlay` 仍表示遮罩。清除旧全局助手输入覆盖，让局部组件负责输入外观。没有加入大面积背景模糊。
