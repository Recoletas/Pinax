# 可组合工作区实施记录

日期：2026-10-10。主工作区 `main`，在既有未提交助手与 UI 修改上实施；没有覆盖旧工作，没有创建提交或部署，也没有重启作者服务。

## 本地实施范围

- AppShell 新增内容组宿主，原路由页面仍为主工作区。资料、来源、正文参考、人物／设定参考、素材／插画、漫画参考和镜头视频以显式资源引用打开。
- 视图位置与资源分离；旁边打开、移到主区、返回、关闭、宽度调整与布局恢复已经接线。展开和手机查看时原页面保持挂载并设为 inert；章节目录、首页和各创作页原布局保留。
- 同一视图移动不重建 DOM；同书主页面切换保留宿主中的媒体和视频面板。跨作品先检查未结束操作，旧任务结果不转移目标。
- 导入和视频任务分别注册关闭检查；异步检查结束后复核布局操作版本。进行中任务的摘要由原组件提供，宿主只订阅，不另建生成执行器。
- 资料路由包装复用显式作用域的 WorkspaceSourcesView，旧 import/sourceId 链接接入同一导入／阅读流程。
- 助手运行时可以打开资料，仍保留当前请求、正式权限、目标与正文审阅。点击检索来源打开资料阅读，不离开 Authoring。
- 检索保留同一块的不同来源归属，使用实际 locator.start，向引用携带 chunkId 和 UTF-16 范围。原文每次至多加载 8 个块；共享／重复块使用归档归属及出现次序定位，避免拼接偏移和重复 Vue key。
- 跑团由会话工作流声明明确世界书作用域；资料查看不推进／切换会话。主内容隐藏时自动推进停止排下一轮，不默认取消已发单轮；联机玩家整库资料入口没有开放。
- 漫画与视频来源可以打开素材或人物参考；顶栏“在旁边打开”可选择本书章节、资料、设定、漫画、素材与分镜视频。选择器按名称搜索，各组最多显示 60 项。
- 镜头视频复用现有生成／查询／停止等待／归档组件，新增内嵌模式；移位或同书导航不卸载查询所有者，正在生成时禁止关闭或切离项目。新提交前直接复核分镜版本；修改镜头仍经原分镜版本保存，旧版本提议不直接覆盖新版本。
- 普通正文打开参考内容时暂时隐藏原 inspector，占用同一右侧空间，不卸载面板；点击已打开的原工具恢复面板而不误触关闭。完整助手主区保持自己的显示方式。中文组合输入期间阻止切换参考内容。
- 正文和编导的全局键盘处理忽略参考组和隐藏主内容；正文历史转发从大页提到已有导航组合函数。

## 续做：助手会话与请求所有者

- 会话、消息、草稿、请求 token 和取消控制器迁入 AppShell 所有的独立 effect scope，按作品分开；正文页挂载时绑定编辑能力，卸载只释放这一绑定。继续使用原 Pi 任务桥与正式存储，没有复制第二套执行器。
- 同书进入资料、设定、漫画等主页面不取消助手；顶部显示运行／新结果状态，可回到任务原章节与会话。手机用产品图标和提示点，操作名称保留在可访问标签中。
- 请求在第一次 await 前捕获原引擎和上下文，迟到结果仍属于原作品。新页面不能通过焦点变化重定向已发任务；跨书和离开作品的导航在任务进行中阻止，正文内部切书入口也接入相同检查。
- 自动修改只有发起时的编辑绑定仍有效才继续应用。期间切页／重建过编辑绑定的结果保留为待审阅提案；回到正文后重新确认当前权限和正文版本，经原事务写入、保护版本及撤销。
- 新挂载的编辑器使用自己的回调，不调用已卸载页面写正文。采用期间禁止导航；审稿、推演草稿、保存失败、导入及输入法的原保护继续保留。
- 应用关闭会停止会话请求并冲刷草稿；普通切页不停止。缓存至多保留 8 个闲置会话所有者，正式历史仍在既有 Repository。刷新不被宣称能自动续跑模型。
- 参考内容重新打开入口从页面上方覆盖按钮移到公共顶栏，避免压住漫画“新建页”等原操作；助手结束后移除已经失效的忙态提示。

## 2026-10-11：完整制作工作台与两区组合（组合验证）

### 实际界面与操作

- 从共用导航打开漫画或视频，打开的是原完整 `ComicStudio` / `ProseEssay` 编辑器。漫画页目录、构图画布、当前格制作，以及编导节点、节拍与镜头时间轴均沿用原组件。
- 制作工作台可放中央，同时在右侧打开资料或设定；也可放回正文旁。两个区域共用同一个宿主，以 Teleport 移动原显示实例，保留页／格、来源、节点选择与本地编辑状态。中央没有再套一个应用导航外壳。
- 工作台顶部可选择本书章节，将当前持久化正文保存为有原章引用的制作素材：漫画进入素材改编入口，编导将素材加入本书画布。重复同章同内容复用素材；正文变化后再次取用产生新的内容快照，不改旧素材。没有点这个操作时不会自动复制书稿。
- “对照原章”通过正文的既有保存／离开守卫打开原章，再把当前制作工作台放到旁边。旧工作台实例仍保留。
- 宽度缩窄后使用本工作台的目录／页面／当前格、场景板／时间轴，以及场景板内部的分区切换。依据容器宽度调整，桌面旁栏也能使用这些操作。移除了嵌入漫画中重复的模式下拉框。

### 数据与生命周期

- 编辑视图使用显式作品引用和自己的轻量路由快照。页／格选择更新视图定位，不把主区正文路由改成漫画页；非本模块的跳转仍交给原路由与守卫。旧漫画／编导路由继续可用；宿主已持有编辑器时，不另建同一份编辑器。
- 每书各一份漫画／编导工作台；通过模块入口重开会复用原实例及定位。单纯移位不调用模型、不重建请求。IME 组合输入时拒绝移动；隐藏编导会清理拖动状态，快捷键只由可见且获得焦点的编辑器处理。
- 关闭或跨作品之前检查画布保存及漫画分页、脚本、图片、上传、编导生成／审阅状态。进行中的任务从公共顶栏可以找回。仍保留原图像请求未知状态与视频供应商取消边界。
- 编导画布由全局七组字段改为按作品保存单一快照。旧画布只按卡片明确的作品归属、或素材的明确归属投影；跨书连线和混书堆不复制，未归属卡不自动认领。第一次保存只写本书新键，旧全局内容不改；其他作品快照不被覆盖。
- 跑团仍沿用单活动会话。查看漫画、编导、资料时可保留原跑团页；半自动在页面不可见时停止排后续步骤。进行中的跑团任务可从顶栏回到现场；离开原页或关闭作品时须等待任务完成。启动作用域先采用明确请求的世界书，避免旧活动世界在加载阶段短暂清掉当前作品的视图。返回跑团优先恢复同世界的明确会话。
