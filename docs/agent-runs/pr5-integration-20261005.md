## 已实施

- 补回最后一次对齐 main 时被回退的桥接扩展：正文/构思/大纲快照、思考增量、工具结果、节拍计划和最终正文。
- 接现有全屏助手与侧栏。写作任务由明确的“写作与修改”入口发起，不用关键词猜测替换资料查询；参考与技法、`@` 键盘选择和当前任务追问已接通。
- 第一次 await 前固定作品、章节、参考和上下文。等待健康检查期间即可停止；切书停止旧任务。真正续接 `/resume`，而非仅修改本地 taskId。
- 对话、命名会话与任务关联存入既有 conversation store。清空当前对话与另开话题分开；资料引用只保存标识，发送时重新读取当前正式资料。
- 采纳经过章节归属、完成状态、保护版本、durable 保存回执和去重检查。保存失败不发布新正文，也不标记已采纳；保存后接既有现场/记忆观察流程。
- 同站 `/api/storyagent` 转到 loopback runtime；服务器凭据不进浏览器。任务使用 capability 哈希命名空间，不开放跨访客列表。主服务可用内置 MiniMax 启动运行时，仍须安装 adapter 依赖。
- 规划步数、取消和输出预算补齐；规划受理后不再重复要求提交。工具结果有界，续接不拆开 tool call/result，服务端最多 4 个活动任务。
- 终态正文替换工具前言。真实模型曾把工具调用打印成代码块，已加入同任务、同预算内的一次修正；仍无法执行则失败。
- 普通体验支持可选 adapter 路由；严格任务合同继续由原生发布前验收/修订处理。没有将独立 shadow 检查当作发布许可。

## 保留边界

本 PR 不完成长篇资料导入、原始文件全文/RAG、自动替换正文/设定、跨模型质量矩阵。新增工具查询有界快照，正文每项最多前 8,000 字符，不可声称通读全书。原任务记录缺失时需显式重新开始任务，对话仍保留。公网没有在本轮部署；服务端不能构建，后续发布仍应本机构建、上传产物并安装适配器依赖。
