# 历史决策材料

这里仅保留少量历史 spec 和开发工具笔记，作为决策背景或实现证据，不是当前工作流，也不承载产品优先级。

查当前内容时，请从以下入口开始：

- [`../PLAN.md`](../PLAN.md)：当前工程边界。
- [`../plan/pinax-integrated-product-roadmap.md`](../plan/pinax-integrated-product-roadmap.md)：当前唯一产品路线图。
- [`../STATUS.md`](../STATUS.md)：当前 session 状态。
- [`../src/known-issues.md`](../src/known-issues.md)：已知风险与限制。

保留材料包括：

- `specs/` 中仍被 RFC、运行时注释或开发流程引用的决策记录；
- `notes/perf-overlay.md`，性能调试开关的简要说明。

已完成的执行计划已删除；新的实施任务必须回到主路线图或对应 RFC，不在本目录新增 plan。
