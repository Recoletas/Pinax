## 助手输入与运行中消息（2026-10-20，本地实施）

输入操作保持同一行，模型名可收缩，默认章节范围收进权限菜单。运行中默认排队发送，另可选择补充到当前任务；队列复用会话存储，支持编辑、移除与恢复，取消/失败/提问时暂停。补充接 pi 原生 steering，在消费确认后进入对话，保留原任务授权与模型。排队项记录文稿，禁止换稿后静默执行。服务启用需更新 Express 和运行包，验证结果与范围见 LOG。

## 助手向作者提问（2026-10-20，本地实施）

新增 request_user_input 工具：消息内展示问题/可选答案和自由输入，回答后沿用原会话、原任务续接；等待时保存状态并释放生成连接，不自动选择或写稿。复用既有会话存储、权限、修改建议与推演链。运行包已隔离验证，并在作者确认后仅更新本地 8451；验证证据与参考源码见 LOG。

## 统一模型配置（2026-10-19，本地实施）

文本、图片、视频合并到“设置 → 模型”；工作区模型名称提供快速选择与“管理模型”。重答和浏览回答版本保留当前权限偏好；发送时冻结模型/权限，助手委托推演沿用同一模型快照。运行器按请求复制配置，不改全局默认；既有配置存储键与公网模型边界保留。需要配套 Express 与 requestModels 运行包，当前服务更新单独确认，验证记录见 LOG。

## 本轮功能整合（本地）

草稿增加按文稿恢复和保存位置回执；漫画补连续生成状态、实际处理进度和目录新建，并接通整章/选段直接生成分镜、明确失败与中断恢复的区分；旧素材入口转到原件或画师，扩展页移除内置工作台清单。沿用原存储与作品归属，不迁移用户正文。本轮尚未提交或发布，实际验证范围见 LOG。

### 漫画界面与 ComfyUI 参考（2026-10-19）

**已本地实施**：页面计划收掉重复素材/页目录，保留作品目录；素材在计划内折叠多选，方案和页码紧凑切换。分镜标题、画面与对白无框编辑，补充字段按需展开，保存/视觉规则裁决仍走原 owner。它只完成计划页这一块，不代表整套漫画制作界面已达到目标。

**调研依据及后续方向**：参考 ComfyUI 的任务、画布、结果组织。其 [App Mode](https://blog.comfy.org/p/from-workflow-to-app-introducing) 暴露选定输入/输出，底层仍执行同一工作流；适合 Pinax 把作者常用操作做简单，把高级节点工作流作为后续可选入口。当前没有替换 Pinax 前端、安装 ComfyUI 或复制其源码。

- **中央画布**：漫画页保持主要空间；选格后在原位置操作，再次生成和候选比较围绕该格展开。布局、排字与生成共享同一选中对象，避免三个表单各维护一套当前格。
- **右栏**：选中格时只显示画面描述、人物/场景参考和当前模型；选中文字时显示排字。高级采样/工作流参数按模型能力展开，空白页与未选中格不铺出全部字段。[官方工作区分区](https://docs.comfy.org/interface/overview)证实其右栏服务于当前选择。
- **生成队列**：统一展示等待、运行、完成、失败和待恢复，并标明作品/页/格。主按钮有固定位置，执行状态不随面板卸载消失。ComfyUI 的 [queueStore](https://github.com/Comfy-Org/ComfyUI_frontend/blob/main/src/stores/queueStore.ts) 与 [executionStore](https://github.com/Comfy-Org/ComfyUI_frontend/blob/main/src/stores/executionStore.ts) 分管任务历史和运行进度；Pinax 需要先把当前内存登记与媒体落盘串成可恢复任务合同，不能仅画一个队列。
- **图片结果**：借鉴[结果预览与分组](https://docs.comfy.org/interface/assets)，在漫画内按页/格显示候选缩略图，打开大图、比较、采用；批次有明确归属。复用现有媒体资产和 take，不恢复独立素材旧页面，也不另建图片存储。
- **进度与恢复**：ComfyUI 的 [/prompt、/history、/ws](https://docs.comfy.org/development/comfyui-server/comms_routes) 支持任务 ID、查询与运行事件。Pinax 已有 `generateWithComfyUi`，但仅提交、轮询并取首张输出，未把 promptId 持久化、未接 WebSocket 进度，且参考图入口明确拒绝。因此已有 adapter 不等于完整工作流接入。MiniMax 同步接口不能凭空显示采样百分比，也不能保证客户端断线后找回供应商未返回的图片。

**本轮本地实施**：画面描述、模型和生成/上传收成一个输入区；候选缩略图先预览，支持原图大小视图、与当前画面对比和明确选用；阶段产物复用预览，保留选候选与阶段确认的区别。重复取景预览折叠；一键补齐移到画面标签旁。画布下方本页状态由原页/格 pending、阶段状态和共享在途身份派生，点击定位到对应格/阶段；没有新增队列真源。

**2026-10-20 本地补充**：当前格描述、景别与画幅优先，上一格不再整段复制；空镜和局部特写隔离全页人物上下文，沿用结构化画风。脚本与分页方案保留镜头字段；普通生图接通原本仅精修使用的显式参考及已确认人物引用，按模型能力、图片归属与可读性检查。独立漫画页补满宿主宽度。已完成 10 次真实图片请求及 v19 补拍合成，完整门禁 exit 0；失败尝试和第四格背影远景未完全遵从的限制见 LOG，不将选用成功镜头称为稳定保证。

后续继续完善人物/场景参考的可发现性和模型能力提示；跨页任务历史、ComfyUI promptId 持久化、WebSocket 进度仍未实施。当前切片不等于完整 ComfyUI 接入。调研基于官方当前文档及公开 main 源码，没有运行 ComfyUI 客户端或真实 ComfyUI 后端，不冒称其每个版本行为均已验证。

当前视觉行定位已完成缩放坐标修复：ProseMirror viewport 坐标、Notebook 局部坐标与 `body.zoom` CSS 坐标必须经同一 geometry helper 转换，禁止把 `getBoundingClientRect()` 结果直接作为缩放容器内的 `top/left/width`。长文档 Gate 至少覆盖第 80 段和 0.85/1.0 缩放。

## 当前工程边界

- `main` 是开发集成分支，`server-version` 是生产适配分支。
- 现有 store 继续拥有各自领域状态；项目 manifest 只负责连接，不复制状态。
- AI 结果经既有采用事务写入；手动确认或有效自动授权都必须检查目标、修订和保存结果。
- 地图、历史、写作和媒体不得各自再建一套项目身份或引用模型。
- 视频供应商逻辑只能进入 server adapter，不继续堆进页面组件。
- 图片、插画和漫画复用同一媒体服务；已删除无逻辑 `ImageGenRail` 兼容壳，`ProseEssay.vue` 不再维护第二套 provider fetch。
- 联机首版只做房主权威的多人冒险；全文、设定和地图实时协作继续暂缓。
- 地理与历史融合保留在产品路线中；当前优先级以本页前部为准，不因历史专项描述替代作者新任务。
- 世界书地点、地图对象和历史地点统一使用 `placeId` 与扩展后的 `geoHistory.placeRefs` 绑定；不得新增平行地点 store。低置信匹配保持未绑定并交给用户审阅，不能用随机陆地点伪装成功。
- UI 继续沿用现有中性表面、明暗动作配对和图标工具轨；保留正文版心与成熟布局，外部产品用于参考信息组织，不作为重做页面的授权。视觉过程见 [视觉对齐工作流](./engineering/visual-alignment-workflow.md)。
