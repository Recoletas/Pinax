## 命令覆盖什么

| 命令 | 用途 |
| --- | --- |
| `npm run docs:build` | VitePress 工程文档构建；不单独证明应用内 Markdown 手册的操作正确 |
| `git diff --check` | 检查改动中的空白/补丁格式问题 |
| `npm run lint:delta` | 当前代码静态检查及增量约束 |
| `npm run build` | Vite 前端生产构建 |
| `npm run architecture:check` | 结构预算和依赖边界 |
| `npm run architecture:build-size` | 构建包体预算，需要已有构建产物 |
| `npm run build:agent-runtime` | 构建固定版本运行包；不是启动或模型调用 |
| `npm run build:knowledge-runtime` | 构建本机知识包；不是项目绑定或实际检索 |
| `npm run verify:full` | StoryAgent 检查、Vitest 预算、lint、前端构建、结构/体积、同步、diff 和文档构建 |
| `npm run verify:ci` | 推送前本地检查：verify:full 加 CI 的无密钥写作旅程和完整工作区备份/恢复旅程；需要已安装 Playwright Chromium |

`verify:full` 不包含 CI 独立运行的两个浏览器 job。推送前使用 `verify:ci` 补齐这两条旅程；它保留网络隔离、真实导入/下载、恢复幂等与写失败保护断言，不代表复刻 GitHub 托管机的安装和缓存环境。

完整门禁命令以 `package.json` 为准。核心 Vitest 预算是总量 **不超过 20 个文件 / 200 个用例**，不是只跑其中一部分。外部仓库或服务缺失导致的 skipped 必须保留在报告里，不能算作通过。

VitePress 当前设置 `ignoreDeadLinks: true`。因此 docs:build 成功不能证明所有相对链接可用；文档更新需另外核对修改文件的本地路径、标题锚点及手册清单。
